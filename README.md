## 快速开始

### 开发环境

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本 (静态导出到 out/ 目录)
npm run build
```

### 部署

本项目使用 Cloudflare Pages 自动部署：
- 推送到 `master` 分支自动触发构建
- 构建命令：`npm run build`
- 输出目录：`out`
