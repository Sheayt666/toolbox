## 六、成交话术（10套）

### 套1：客户犹豫时（共情+推一把）

```
我特别理解你的顾虑，买之前都会犹豫的。
说实话这个价格真的不贵，你买回去【价值点，如：随便用里面一个方法都值回票价了/省下来的时间都不止这点钱】。
而且不满意随时找我，我不会让你吃亏的。
要不先试试？说不定能给你带来惊喜呢~
```

### 套2：客户犹豫时（稀缺性）

```
这个价格是活动价哦，过两天就要恢复原价【X元】了。
现在入手最划算，以后想买就贵啦。
而且前【X】名下单还送【赠品】，
送完就没有了，要的话抓紧哦~
```

### 套3：嫌贵时（价值塑造）

```
我明白你觉得有点贵，但是你想想：
【拆解价值，如：里面光XX就值XX钱了，还有XX和XX，加起来远超这个价格】
而且是永久使用+免费更新，越用越值。
比起你自己花时间到处找资料，花这点钱省下来的时间精力才是最值钱的。
```

### 套4：嫌贵时（对比法）

```
你可以去对比一下，别家类似的都要【X元】，
我家这个价格真的是良心价了。
而且我家内容【优势，如：更全/更新/有售后】，
不是那种随便拼凑的垃圾资源。
一分钱一分货，买回去能用才是真的省钱。
```

### 套5：嫌贵时（降价有条件）

```
这样吧，看你也是真心想要，
```

### 套6：问值不值时（自信回应）

```

买过的宝子基本都是好评，很多还回来复购。
我自己也在用，觉得没用的东西我不会拿出来卖的。
而且你放心，有任何问题我都负责，
真觉得不值的话，咱们再商量。

```
