# 闲鱼自动回复设置指南

> 用好自动回复，提升转化率，减少重复劳动
> 适用对象：闲鱼虚拟产品卖家 / 数字资料店铺

---

## 一、闲鱼自动回复设置步骤

### 步骤1：进入设置入口

打开闲鱼APP → 我的 → 右上角设置图标 → 聊天设置 → 自动回复设置

### 步骤2：开启自动回复

在"自动回复设置"中，打开"离开自动回复"开关

### 步骤3：设置回复内容

根据下面的模板，选择适合你风格的话术填入

### 步骤4：设置生效时间

可以设置全天自动回复，也可以设置特定时间段（如夜间、工作时间）

## 二、关键词自动回复设置建议

### 什么是关键词回复？

当客户发送的消息中包含你设置的关键词时，系统会自动回复预设内容。

### 设置路径

闲鱼APP → 我的 → 我发布的 → 选择商品 → 编辑 → 往下找到"自动回复" → 添加关键词回复

### 设置原则

1. **关键词要精准**：覆盖客户最常问的问题
2. **回复要简洁**：自动回复只是引导，不要太长
3. **留有余地**：告诉客户"有其他问题可以继续问"
4. **分层设置**：不同问题不同回复，不要一条回复回答所有问题

### 推荐设置的关键词组合

| 关键词 | 触发场景 | 回复方向 |
|--------|----------|----------|
| 在吗 / 在不在 / 有人吗 | 打招呼 | 欢迎语 + 引导提问 |
| 价格 / 多少钱 / 便宜 | 问价格 | 报价 + 价值塑造 |
| 怎么买 / 怎么拍 / 下单 | 购买流程 | 购买指引 |
| 发货 / 怎么发 / 什么时候发 | 发货问题 | 发货说明 |
| 内容 / 有什么 / 目录 | 产品内容 | 内容介绍 + 引导看详情 |
| 更新 / 会更吗 | 更新问题 | 更新承诺 |
| 退款 / 退吗 / 能退吗 | 售后问题 | 售后说明 |
| 手机 / 能用吗 | 使用问题 | 使用说明 |

## 五、自动回复设置注意事项

### 1. 不要完全依赖自动回复

自动回复只是辅助，客户看到自动回复后继续追问的，一定要人工跟进。
只靠自动回复的转化率很低，及时的人工回复才是成交关键。

### 2. 自动回复语气要像真人

不要太官方太生硬，加点语气词、表情符号，
让客户感觉是真人在回复，而不是机器人。

### 3. 不要设置太多关键词

5-10个核心关键词就够了，
太多了反而容易混乱，回复不到点子上。

### 4. 定期检查和更新

根据客户常问的问题，定期调整关键词和回复内容，
让自动回复越来越精准。

### 5. 敏感词注意

自动回复里尽量避免出现：微信、加V、私聊、外部链接等敏感词，
容易被平台检测限流。
引导私域用谐音或放在图片里更安全。

### 6. 分商品设置不同回复

如果店铺有多个不同类型的产品，
最好每个商品单独设置关键词回复，
回复内容更精准，转化率更高。

## 六、高效回复技巧

### 技巧1：预判客户问题

客户问第一个问题的时候，就把他接下来可能问的问题一起回答了，
减少来回沟通的次数。

**例：**
客户问"多少钱" → 回答价格 + 包含内容 + 发货时间 + 现在下单福利

### 技巧2：用"三段式"回复

- 第一段：直接回答问题
- 第二段：补充相关信息（价值/福利）
- 第三段：引导行动（下单/加微信/好评）

### 技巧3：善用表情符号

适当加一些表情 😊✨🎁⚡，
让文字更有温度，不像机器人。
但也不要加太多，一两个就够了。

### 技巧4：建立自己的话术库

把常用的回复都整理成快捷短语，
按场景分类，需要的时候一键发送，
效率提升好几倍。
