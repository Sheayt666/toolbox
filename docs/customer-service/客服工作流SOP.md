# 客服工作流 SOP

> 标准化客服工作流程，提升服务质量和转化效率
> 适用场景：闲鱼 + 小红书 虚拟产品客服
> 核心理念：快速响应、专业解答、真诚服务、促成转化

---

## 一、每日客服工作清单

### 【早上 9:00-9:30】晨间检查

- [ ] 检查闲鱼消息：未读消息全部回复
- [ ] 检查小红书私信：未读消息全部回复
- [ ] 检查小红书评论：新评论逐一回复
- [ ] 检查待发货订单：立即发货
- [ ] 检查待评价订单：梳理需要催评的客户

### 【上午 9:30-12:00】黄金回复时段

- [ ] 实时回复新消息（尽量5分钟内）
- [ ] 跟进意向客户（昨天咨询过但没下单的）
- [ ] 处理售后问题（补发链接、解答使用问题）
- [ ] 记录新的常见问题，更新FAQ话术

### 【中午 12:00-14:00】间歇维护

- [ ] 午间快速回复一轮消息
- [ ] 可设置自动回复（注明"午间休息，下午回复"）
- [ ] 重要消息优先回复

### 【下午 14:00-18:00】重点转化时段

- [ ] 实时回复所有消息
- [ ] 跟进上午的意向客户，推动成交
- [ ] 处理已下单客户的售后和引导加私域
- [ ] 整理当日新增客户，标记重点客户

### 【晚上 18:00-22:00】高流量时段

- [ ] 实时回复（晚上是咨询高峰期）
- [ ] 催好评（收货3天以上的客户集中催一次）
- [ ] 引导加私域（已成交客户批量引导）
- [ ] 复盘当日数据：咨询量、成交数、转化率

### 【睡前 22:00-22:30】当日收尾

- [ ] 最后回复一遍所有未读消息
- [ ] 设置夜间自动回复
- [ ] 记录当日遇到的特殊问题
- [ ] 规划第二天重点跟进的客户

## 二、回复时效要求

### 不同时段响应标准

| 时间段 | 响应时间 | 说明 |
|--------|----------|------|
| 工作时间 9:00-22:00 | 5分钟内 | 黄金时段尽量秒回 |
| 午间 12:00-14:00 | 30分钟内 | 可设置自动回复告知 |
| 夜间 22:00-次日9:00 | 次日早9点前 | 睡前尽量回复一遍 |

### 响应速度与转化率的关系

- **1分钟内回复**：转化率最高，客户热度最高
- **5分钟内回复**：良好，客户还在关注
- **30分钟内回复**：一般，客户可能已经去看别家了
- **1小时以上回复**：很差，基本流失了

### 提升响应速度的方法

1. 手机闲鱼/小红书开启消息通知
2. 设置关键词自动回复，解决80%常见问题
3. 常用话术存为快捷短语，一键发送
4. 高峰期专注回复，不做其他事情
5. 忙不过来时设置自动回复告知"稍等，正在回复"

## 三、客户分级处理

### A级客户（高意向，优先处理）

**特征：**
- 问了3个以上问题
- 问到价格、购买方式
- 表达了明确的需求
- 回复速度快，沟通积极

**处理策略：**
- 优先回复，秒回级别
- 主动提供更多信息
- 适当逼单，推动成交
- 下单后重点维护，引导好评+加私域

### B级客户（中等意向，正常跟进）

**特征：**
- 问了1-2个问题
- 有兴趣但还在观望
- 回复速度一般
- 问完就不见了

**处理策略：**
- 按正常速度回复
- 回答问题后留一个钩子（如"现在下单有赠品"）
- 24小时后跟进一次，问问考虑得怎么样
- 持续有互动就升级为A级

### C级客户（低意向，简单回复）

**特征：**
- 只问"在吗""多少钱"
- 问完就没影了
- 态度冷淡，回复简短
- 感觉是随便问问

**处理策略：**
- 正常回复即可，不用花太多时间
- 回答简洁明了，不主动展开
- 留个联系方式/引导关注，万一以后需要呢
- 不要过度推销，引起反感

### D级客户（问题客户，谨慎处理）

**特征：**
- 一上来就砍价砍到离谱
- 要求很多，态度不好
- 问很多奇怪的问题
- 感觉像是来找事的

**处理策略：**
- 保持礼貌，不卑不亢
- 能成交就成交，不能成交也无所谓
- 明确规则，不做过多妥协
- 宁可少赚，也不要招惹麻烦客户

## 四、常见问题处理流程

### 流程1：新客户咨询 → 成交

```
客户打招呼/提问
    ↓
及时回复（热情/专业，根据风格）
    ↓
了解客户需求（买什么、干什么用、有什么顾虑）
    ↓
针对性解答问题（产品介绍 + 价值塑造）
    ↓
客户有顾虑？→ 打消顾虑（售后承诺/价值对比/成功案例）
    ↓
推动下单（限时优惠/赠品/稀缺性）
    ↓
客户下单 → 立即发货 + 感谢
    ↓
引导加私域 + 邀请好评
```

### 流程2：发货流程

```
收到订单提醒
    ↓
确认付款状态
    ↓
找到对应产品的网盘链接
    ↓
通过私信发送链接 + 使用说明
    ↓
发送话术："已发货~ 链接在上面，保存到网盘就能用了，
有问题随时找我哦~ 满意的话记得帮我好评呀 ❤"
    ↓
记录客户信息（昵称、买的什么、日期）
    ↓
标记为"已发货，待好评"
```

### 流程3：售后问题处理

```
客户反馈问题
    ↓
第一时间回应（"别着急，我来帮你看看"）
    ↓
了解具体问题（什么问题、怎么出现的、截图看看）
    ↓
判断问题类型：
    ├─ 链接失效 → 立即补发新链接
    ├─ 不会使用 → 耐心指导操作
    ├─ 内容缺失 → 核实后补发
    ├─ 要求退款 → 按规则处理（见下方退款流程）
    └─ 其他问题 → 具体问题具体分析
    ↓
解决后跟进确认（"现在可以了吗？还有问题随时找我"）
    ↓
记录问题，优化产品或话术
```

### 流程4：退款要求处理

```
客户提出退款
    ↓
先了解原因（为什么要退？哪里不满意？）
    ↓
判断情况：
    │
    ├─ 还没发货 → 直接同意退款，不要纠结
    │
    ├─ 产品确实有问题 → 协商解决：
    │   ├─ 能补发/补充的，优先补发
    │   ├─ 客户坚持要退，视情况部分退款
    │   └─ 态度强硬的，全额退款止损
    │
    ├─ 客户个人原因（买错了/不想要了）→
    │   ├─ 先说明虚拟产品不支持退款
    │   ├─ 给出替代方案（补其他内容/换其他产品）
    │   └─ 客户不接受，看情况处理（差评风险大就退）
    │
    └─ 恶意退款/白嫖党 →
        ├─ 明确拒绝，说明规则
        ├─ 准备好证据（发货记录、聊天记录）
        └─ 走平台介入，维护自己权益
```

### 流程5：差评处理

```
收到差评提醒
    ↓
第一时间私信客户（态度诚恳，先道歉）
    ↓
了解差评原因
    ↓
提出解决方案（补偿/补发/退款）
    ↓
客户接受方案 → 请求修改/删除差评
    ↓
客户不接受 → 公开回复评价（客观说明，不撕逼）
    ↓
总结原因，避免下次再出现
```

## 五、升级处理机制

### 什么情况需要升级处理？

1. **客户情绪激动**：骂人、威胁差评、说要投诉
2. **超出权限范围**：客户要求超出了你能决定的范围
3. **复杂售后问题**：纠缠不清、难以判断责任
4. **大量客户反馈同一问题**：可能是产品本身有问题
5. **平台介入**：客户申请了平台介入/投诉

### 升级处理步骤

**第一步：稳住客户情绪**
- 先道歉，不管谁的错，先让客户消气
- "非常抱歉给你带来不好的体验了"
- "你先消消气，咱们好好说，我一定给你解决"

**第二步：了解完整情况**
- 让客户把事情经过说清楚
- 查看聊天记录、订单记录
- 收集相关截图证据

**第三步：给出解决方案**
- 在自己权限范围内给出最优方案
- 方案要具体，不要含糊其辞
- 给出两个选项让客户选（增加接受度）

**第四步：超出权限及时上报/请示**
- 如果是自己一个人做，就问自己：这个损失我能接受吗？
- 能接受就直接处理，不能接受就再协商
- 原则：小损失直接认，大损失尽量协商减少损失

**第五步：记录和复盘**
- 每一个升级处理的案例都要记录
- 分析原因，是产品问题还是话术问题
- 优化流程，避免下次再出现

### 差评/投诉升级处理红线

| 情况 | 处理方式 | 底线 |
|------|----------|------|
| 确实是产品问题 | 全额退款 + 道歉 | 产品问题不辩解 |
| 服务不到位 | 道歉 + 补偿 | 态度问题必须认 |
| 客户误会了 | 耐心解释 + 补偿 | 解释也要给台阶 |
| 恶意差评 | 准备证据 + 公开回复 | 不撕逼，留证据 |
| 平台介入 | 提交证据 + 积极配合 | 按平台规则来 |

## 六、客服数据化管理

### 每日数据记录

| 数据项 | 记录内容 | 作用 |
|--------|----------|------|
| 咨询人数 | 当天多少人来问 | 衡量流量质量 |
| 成交人数 | 当天下单多少人 | 衡量转化率 |
| 转化率 | 成交人数/咨询人数 | 核心指标，目标30%+ |
| 客单价 | 总销售额/成交人数 | 衡量产品定价 |
| 好评数 | 当天新增多少好评 | 衡量服务质量 |
| 差评/售后 | 当天多少问题 | 衡量产品和服务问题 |
| 加私域数 | 当天多少人加微信 | 衡量私域转化 |

### 每周复盘

- 本周转化率是升了还是降了？为什么？
- 客户问得最多的问题是什么？话术要不要优化？
- 售后问题主要集中在哪方面？产品要不要改进？
- 哪款产品卖得最好？要不要加大推广？
- 哪款产品卖不动？要不要下架或优化？

### 每月总结

- 月度总销售额、总订单量
- 转化率趋势（越来越好还是越来越差）
- 客户来源分析（闲鱼自然流量/小红书引流/其他）
- 好评率、复购率
- 下月目标和优化方向

## 七、客服心态建设

### 遇到难搞的客户怎么办？

1. **不生气**：客户是对事不对人，不要往心里去
2. **不辩解**：先认再说，争赢了道理输了生意
3. **不纠缠**：能解决就解决，解决不了就认栽，别浪费时间
4. **不妥协到底线之外**：该坚持的原则还是要坚持

### 如何保持热情？

1. 把每一个客户都当成第一个客户
2. 想象对面是一个真实的人，不是冰冷的屏幕
3. 每天给自己定小目标，达成了给自己奖励
4. 定期休息，不要一直盯着手机

### 被差评了怎么办？

1. 先处理情绪，再处理事情
2. 能挽回就挽回，不能挽回就接受
3. 一个差评不会毁了你的店，产品好才是硬道理
4. 从差评里学习，让自己变得更好

---

> 💡 客服不是简单的回消息，而是销售 + 服务 + 关系维护的综合体。
> 好的客服能让转化率翻倍，差的客服能把到手的生意聊黄。
> 用心对待每一个客户，回报一定会来的。
