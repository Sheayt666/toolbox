# 推荐10个我日常用的在线开发工具，效率翻倍不是说说而已

作为一个每天和代码打交道的前端开发，我深知"工欲善其事，必先利其器"的道理。这几年我收藏了不少在线开发工具，有些用了一次就吃灰，有些却成了每天必开的"效率神器"。

今天整理了一下我收藏夹里那些真正好用、真正能帮我省时间的在线工具，分享给大家。都是免费的，不用翻墙，打开浏览器就能用。

---

## 1. JSON 格式化工具 —— 后端甩过来的 JSON 终于能看了

做前端的同学应该都有同感：后端接口返回的 JSON 有时候密密麻麻一大坨，根本没法看。以前我都是自己写个小脚本格式化，后来发现了在线工具，直接粘贴进去一键格式化，还能折叠层级、高亮语法，找字段方便多了。

我常用的是 **工具箱** 里的 JSON 格式化工具，支持 2/4 空格缩进切换、压缩、转义/反转义，甚至还能直接转成 TypeScript 接口定义。对于需要和接口文档对齐的场景，这个 TS 转换功能真的省了我不少手动写类型的时间。

## 2. 正则表达式测试器 —— 写正则不再靠猜

正则这东西，写的时候信心满满，跑起来满屏报错。说的就是我本人。

以前调试正则，得写个 test.html 或者在控制台里反复试。现在直接用在线正则测试器，输入正则和测试文本，实时看到匹配结果，还能显示捕获组。工具库里的正则测试器还自带常用正则模板（手机号、邮箱、身份证、URL 等等），省得每次都去搜。

有一次我要写一个提取 HTML 中所有图片链接的正则，在测试器里边调边看，两分钟搞定。搁以前至少得折腾十几分钟。

## 3. Base64 编解码 —— 小图片转 Base64 太方便了

有时候做个小 demo，不想搞图片资源管理，直接把小图标转成 Base64 嵌在 CSS 里，省事。还有和后端对接的时候，经常遇到 Base64 编码的字段需要解码看内容。

这个 Base64 工具支持文本和图片互转，直接拖图片进去就能拿到 Base64 字符串，或者把 Base64 粘贴进去预览图片。比打开命令行敲 base64 命令方便多了。

## 4. URL 编解码 —— 调试接口必备

做 Web 开发的，URL 编码解码是家常便饭。尤其是排查中文字符乱码问题的时候，在线解码一下就能看到原始内容。

这个工具支持一键编码/解码，还能处理整个 URL 中的 query 参数，自动解析成 key-value 列表，比手动一个个解码高效太多。

## 5. 时间戳转换 —— 再也不用心算时间了

看日志、查数据库，到处都是 Unix 时间戳。以前我还会在心里大概算一下是哪年哪月，现在直接粘进去转成北京时间，精确到毫秒。还支持反过来把日期转成时间戳，写测试数据的时候特别好用。

## 6. 二维码生成器 —— 分享链接的利器

做 H5 页面的时候，经常需要生成二维码让同事扫码测试。这个工具能直接输入文本或链接生成二维码，还能调整大小和容错级别。虽然简单，但用得真的多。

## 7. 颜色转换工具 —— 设计师给的色值终于不用手动换了

设计师给的设计稿里，有时候是 HEX，有时候是 RGBA，还有时候是 HSL。这个颜色转换工具支持 HEX、RGB、RGBA、HSL 之间互转，还能实时预览颜色，选配色的时候也能用上。

## 8. Markdown 编辑器 —— 写文档不用装软件

虽然我本地也装了 Typora，但有时候临时需要写个 README 或者文档片段，直接用在线 Markdown 编辑器就行，左边写右边预览，写完复制出来。支持导出 HTML，偶尔需要发个富文本格式的内容也能用。

## 9. 哈希计算 —— MD5/SHA 一键搞定

需要算个文件的 MD5 校验值，或者给字符串做个哈希，不用再找命令行了。这个工具支持 MD5、SHA-1、SHA-256、SHA-512 等常见哈希算法，输入文本直接出结果。

## 10. UUID 生成器 —— 测试数据随手来

写测试用例、造假数据的时候经常需要唯一 ID。UUID 生成器一键生成多个 UUID，想用多少用多少，比自己写循环生成方便多了。
