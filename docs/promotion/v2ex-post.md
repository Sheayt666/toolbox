# 做了一个免费在线工具箱，分享给大家

最近做了一个面向开发者的在线工具箱网站，完全免费、无广告、不需要注册，打开浏览器就能用。

## 为什么做这个？

平时开发中经常需要用到各种小工具：JSON 格式化、正则测试、Base64 编解码、时间戳转换……每次都要去搜索引擎找，要么是满屏广告的垃圾站，要么是功能单一需要一个个收藏。

干脆自己做了一个聚合工具箱，把常用的开发工具都集中在一起，界面清爽，用着顺手。

## 技术栈

- 前端：Vue 3 + Vite + TypeScript
- UI：Tailwind CSS
- 部署：Vercel
- 纯前端实现，所有数据处理都在浏览器本地完成，不上传服务器，隐私安全

## 目前有哪些工具？

- JSON 格式化/压缩/转 TS 接口
- 正则表达式测试器（支持常用模板）
- Base64 编解码（支持文本和图片）
- URL 编解码
- 时间戳转换
- 二维码生成
- 颜色格式转换（HEX/RGB/HSL）
- Markdown 编辑器
- 哈希计算（MD5/SHA 系列）
- UUID 生成器
- 文本对比
- 随机数生成

一共 12 个工具，后续打算继续加。
