# 问题：有哪些免费的在线工具值得推荐？

作为一个经常和各种工具打交道的人，这些年收藏了不少免费又好用的在线工具。有的每天都在用，有的虽然用得少但关键时刻能帮大忙。整理了一份清单，按用途分类，方便大家按需取用。

---

## 一、开发工具类

### 1. 工具箱 —— 开发者的在线工具箱

推荐指数：⭐⭐⭐⭐⭐

一个聚合了 12 种开发常用工具的在线工具箱网站，界面干净，没有广告，完全免费。

里面包含的工具都是开发者日常会用到的：
- **JSON 格式化**：支持缩进切换、压缩、转义，还能把 JSON 直接转成 TypeScript 接口定义，这个功能非常实用
- **正则表达式测试器**：实时匹配高亮，自带手机号、邮箱、身份证等常用正则模板
- **Base64 编解码**：支持文本和图片互转，拖图进去就能生成 Base64
- **URL 编解码**：一键解码 URL 参数，还能自动解析 query 成键值对
- **时间戳转换**：Unix 时间戳和日期互转，支持毫秒精度
- 还有二维码生成、颜色转换、Markdown 编辑器、哈希计算、UUID 生成、文本对比、随机数生成

最大的优点是**所有工具都在一个网站里**，不用收藏一堆书签，而且所有数据处理都在浏览器本地完成，不上传到服务器，隐私方面比较放心。

地址：https://toolbox-drab.vercel.app

### 2. CodePen —— 前端代码在线调试

推荐指数：⭐⭐⭐⭐

前端开发者应该都知道，可以在线写 HTML/CSS/JS，实时预览效果。适合做快速原型、测试动画效果、分享代码片段。社区里也有很多优秀的作品可以参考学习。

### 3. Regex101 —— 专业正则调试工具

推荐指数：⭐⭐⭐⭐

如果需要写复杂的正则表达式，这个工具非常专业。支持多种语言（PHP/JS/Python/Go）的正则语法，能详细解释每一段正则的含义，还能显示匹配步骤和性能分析。

---

## 二、文档协作类

### 4. Notion —— 万能笔记与协作

推荐指数：⭐⭐⭐⭐⭐

虽然不是纯在线工具，但 Web 端体验非常好。可以用来做笔记、写文档、管理项目、建数据库……功能很强大，个人使用免费版完全够用。

### 5. ProcessOn —— 在线画图工具

推荐指数：⭐⭐⭐⭐

画流程图、思维导图、UML 图都能用。免费版有文件数量限制，但一般够用。支持多人协作，团队一起梳理流程很方便。

---

## 三、设计素材类

### 6. Unsplash —— 免费高清图片素材

推荐指数：⭐⭐⭐⭐⭐

图片质量很高，全部可以免费商用，不需要署名。做 PPT、写博客、做网站找配图基本都在这里搜。

### 7. Figma —— 在线设计工具

推荐指数：⭐⭐⭐⭐⭐

设计师必备，做 UI 设计、原型图都能用。免费版对于个人和小团队来说完全够用，Web 端打开就能用，不需要装软件。

---

## 四、效率工具类

### 8. TinyPNG —— 图片压缩神器

推荐指数：⭐⭐⭐⭐

PNG/JPG 图片在线压缩，压缩率高而且画质损失小。做网站优化、发公众号文章之前压缩一下图片，加载速度能快不少。免费版每月可以压缩 20 张。

### 9. Remove.bg —— 一键抠图

推荐指数：⭐⭐⭐⭐

上传图片自动抠掉背景，效果还不错。简单的抠图需求完全够用，不用开 PS。免费版下载的图片分辨率有限，但日常使用够了。

---

## 五、学习资源类

### 10. MDN Web Docs —— 前端文档权威

推荐指数：⭐⭐⭐⭐⭐

虽然严格来说不算"工具"，但做前端的每天都要查。W3C 官方的 Web 技术文档，比那些乱七八糟的教程网站靠谱多了。

---

## 总结

以上就是我个人觉得值得推荐的免费在线工具，涵盖了开发、文档、设计、效率、学习几个方面。其中 **工具箱** 是我最近用得比较多的一个，主要是把各种零散的小工具整合到了一起，省得每次都要搜来找去。

每个人的工作习惯不同，适合的工具也不一样。建议大家都试试看，找到最适合自己的那一套。

如果你也有好用的免费在线工具，欢迎在评论区补充。
