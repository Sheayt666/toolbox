# 发货自动化说明

## 一、自动发货流程说明

### 1.1 整体流程

```
买家下单付款 → 系统自动触发 → 发送网盘链接和提取码 → 买家下载使用 → 引导好评
```

### 1.2 发货方式选择

**推荐方案：闲鱼自动发货工具 + 百度网盘/阿里云盘**

| 发货方式 | 优点 | 缺点 | 推荐度 |
|---------|------|------|--------|
| 闲鱼自动发货机器人 | 全自动，无需人工 | 需要第三方工具，有成本 | ⭐⭐⭐⭐⭐ |
| 手动复制粘贴发送 | 零成本 | 费时间，无法24小时 | ⭐⭐ |
| 邮箱自动发送 | 稳定 | 买家可能不看邮箱 | ⭐⭐⭐ |

### 1.3 自动发货工具推荐（闲鱼）

1. **易出单自动发货** - 支持关键词自动回复、自动发链接
2. **闲鱼管家** - 支持自动发货、订单管理
3. **速飞鱼** - 专门做虚拟商品自动发货

**设置步骤：**
1. 注册登录自动发货工具
2. 绑定闲鱼账号
3. 设置触发关键词（如"发货""你好""在吗"等）
4. 上传网盘链接和提取码
5. 设置自动回复规则
6. 开启自动发货功能

### 1.4 手动发货流程（备用）

如果自动发货工具暂时不可用，手动发货流程：

1. 收到订单通知
2. 复制对应产品的网盘链接和提取码
3. 打开闲鱼APP，找到买家
4. 粘贴发货信息并发送
5. 附上使用说明和注意事项
6. 引导好评

## 五、提高转化率的小技巧

1. **自动回复设置** - 设置关键词自动回复，买家发"你好""在吗"自动发产品介绍
2. **鱼塘发帖** - 去相关鱼塘发帖引流（如副业鱼塘、程序员鱼塘、效率工具鱼塘）
3. **擦亮宝贝** - 每天擦亮宝贝，提高曝光率
4. **多账号操作** - 有条件的话可以多开几个账号，增加曝光
5. **赠品策略** - 买就送小赠品，提高转化率和好评率
6. **限时优惠** - 不定期做限时优惠活动，促进下单
7. **好评截图** - 把好评截图放到商品图片里，增加信任感

## 六、注意事项

1. 不要在闲鱼直接发微信/QQ等联系方式，容易被检测违规
2. 不要出现"培训""课程""加盟"等敏感词
3. 商品描述不要夸大宣传，实事求是
4. 及时回复买家消息，响应速度影响排名
5. 定期更新网盘链接，防止失效
6. 保存好买家聊天记录，有纠纷时作为凭证
7. 遵守平台规则，诚信经营
