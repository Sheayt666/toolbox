# 7天快速启动计划表

> 目标：用7天时间，完成从0到1的产品上架和推广启动，跑通最小闭环。
>
> 适用人群：有一个虚拟产品/资料/工具，想快速验证市场的新手。

---

## 启动前准备（启动前一天完成）

### 需要提前准备好的东西

| 类别 | 具体内容 | 是否完成 |
|------|---------|---------|
| 产品 | 1款核心产品（资料/工具/教程） | ☐ |
| 产品包装 | 产品介绍文案、主图、详情图 | ☐ |
| 物料 | 网盘资源整理好、分享链接生成好 | ☐ |
| 账号 | 手机号2个（主号+小号） | ☐ |
| 工具 | 手机2部（或者一部手机+电脑） | ☐ |
| 时间 | 每天至少2小时，连续7天 | ☐ |

### 心态准备

- 不要追求完美，先跑起来再优化
- 前几天没流量没订单很正常，不要灰心
- 重点是完成动作，而不是追求结果
- 7天后根据数据调整方向，而不是放弃

## 第1天：账号注册 + 产品上架

### 今日目标
完成闲鱼账号注册和3款产品上架。

### 时间安排
- 上午：账号注册 + 养号基础操作（30分钟）
- 下午：产品素材准备（1小时）
- 晚上：上架3款产品（1小时）

### 具体任务清单

**任务1：注册闲鱼账号（30分钟）**
- [ ] 下载闲鱼APP
- [ ] 用淘宝/支付宝账号登录
- [ ] 完成实名认证
- [ ] 授权芝麻信用
- [ ] 设置头像（真人或真实感头像）
- [ ] 设置昵称（不要营销感太强）
- [ ] 完善个人简介
- [ ] 浏览首页20分钟，点赞收藏10个宝贝

**任务2：准备3款产品素材（60分钟）**
- [ ] 第1款：引流款（低价，比如9.9元）
  - [ ] 主图1张（大字报风格，突出卖点）
  - [ ] 详情图3-5张（产品展示、内容清单、购买说明）
  - [ ] 标题1个（30字内，包含核心关键词）
  - [ ] 详情文案1段（痛点+产品+信任+行动）

- [ ] 第2款：主力款（中价，比如29.9元）
  - [ ] 主图1张
  - [ ] 详情图5-7张
  - [ ] 标题1个
  - [ ] 详情文案1段

- [ ] 第3款：利润款（高价，比如69元）
  - [ ] 主图1张
  - [ ] 详情图7-9张
  - [ ] 标题1个
  - [ ] 详情文案1段

**任务3：上架3款产品（60分钟）**
- [ ] 上架第1款（引流款）
- [ ] 上架第2款（主力款）
- [ ] 上架第3款（利润款）
- [ ] 每款发布后分享到1-2个相关鱼塘
- [ ] 用小号给自己的产品点"想要"和"超赞"

### 今日关键动作
1. 3款产品必须全部上架，哪怕不完美
2. 标题一定要包含关键词
3. 主图一定要清晰、有文字

### 今日不做什么
- 不要花一整天纠结图片好不好看
- 不要反复改标题和价格
- 不要一直刷看有没有人浏览

**任务3：写第一篇小红书笔记（90分钟）**
- [ ] 确定笔记主题（推荐：干货分享类，容易出爆款）

2. 闲鱼每天坚持擦亮
3. 关注数据，但不要焦虑

### 今日避坑
- 第一篇笔记不要发硬广
- 不要在笔记里留联系方式
- 不要纠结数据，发出去就是胜利

## 第3天：掘金发帖 + 知乎回答

### 今日目标
在掘金发一篇技术文章，在知乎回答3个相关问题。

### 时间安排
- 上午：闲鱼日常 + 小红书互动（30分钟）
- 下午：掘金文章（1.5小时）
- 晚上：知乎回答（1小时）

### 具体任务清单

**任务1：日常维护（30分钟）**
- [ ] 闲鱼擦亮3款产品
- [ ] 回复闲鱼消息
- [ ] 查看小红书笔记数据
- [ ] 回复小红书评论
- [ ] 给同行的笔记点赞评论

**任务2：掘金发文章（90分钟）**
- [ ] 注册掘金账号（如果还没有）
- [ ] 完善个人资料（头像、简介、技能标签）
- [ ] 确定文章主题
  - 推荐：教程类、工具推荐类、实战项目类
- [ ] 写文章（1500-2000字）
  - 开头：背景/痛点引入
  - 正文：分点详细写，加代码示例/截图
  - 结尾：总结 + 自然提到你的产品
- [ ] 选好分类和标签
- [ ] 做一张封面图
- [ ] 上午10点左右发布
- [ ] 发布后回复评论

**掘金文章选题参考：**
- 我用Python写了一个XX脚本，效率提升10倍
- 推荐几个私藏的效率工具
- 从零实现一个XX工具（附源码）
- 工作3年，我总结的XX经验

**任务3：知乎回答（60分钟）**
- [ ] 注册/登录知乎账号
- [ ] 完善个人资料
- [ ] 关注5个相关话题
- [ ] 搜索相关关键词，找3个合适的问题回答
  - 优先选：关注人数多 + 回答数不太多的
- [ ] 每个回答写200-500字
  - 先给出直接答案
  - 再分点详细说明
  - 自然植入你的产品/资料
- [ ] 发布回答

**知乎找问题的方法：**
1. 搜索关键词，按"最多赞同"排序，找高关注问题
2. 搜索关键词，按"最新"排序，找新提出的问题
3. 在话题页面找"等待回答"的问题

### 今日关键动作
1. 掘金文章必须是干货，不能是纯广告
2. 知乎回答先解决问题，再提你的产品
3. 每个平台都要互动，不要发完就走

### 今日避坑
- 掘金文章不要标题党
- 知乎回答不要复制粘贴同样的内容
- 不要在正文里直接甩链接

## 第6天：小红书第三篇笔记 + 数据分析

### 今日目标
发布小红书第三篇笔记，做一次全面的数据分析。

- 上午：日常维护 + 数据整理（1小时）
- 下午：小红书第三篇笔记（1.5小时）
- 晚上：深度数据分析 + 优化方案（1小时）

### 具体任务清单

**任务1：日常维护（30分钟）**
- [ ] 闲鱼擦亮产品
- [ ] 回复所有消息和评论
- [ ] V2EX帖子继续互动

**任务2：数据整理（30分钟）**
- [ ] 整理这6天的所有数据
- [ ] 填入下面的关键指标追踪表
- [ ] 标出表现最好和最差的内容

**任务3：小红书第三篇笔记（90分钟）**
- [ ] 选题：经验分享/故事类（建立人设和信任）
  - 例："我是怎么从零开始做XX的"
  - 例："做XX一个月，我赚了多少钱"
- [ ] 制作封面图
- [ ] 写正文（故事+干货结合）
- [ ] 选标签

**任务4：深度数据分析（60分钟）**

分析维度：

**闲鱼数据：**
- 哪款产品浏览量最高？标题/主图有什么特点？
- 浏览到"想要"的转化率是多少？
- "想要"到咨询的转化率是多少？
- 咨询到下单的转化率是多少？
- 哪个时间段咨询的人最多？

**小红书数据：**
- 两篇笔记哪篇数据好？为什么？
- 点击率怎么样？（封面+标题的效果）
- 收藏率怎么样？（内容价值的体现）
- 评论率怎么样？（互动引导的效果）
- 涨粉了多少？

**其他平台数据：**
- 掘金文章阅读量、点赞、评论
- V2EX帖子回复数
- 知乎回答赞同数

**根据数据制定优化方案：**
- 表现好的内容 → 这个方向可以多做
- 表现差的内容 → 找出原因，下次改进
- 转化率低的环节 → 针对性优化

### 今日关键动作
1. 第三篇笔记发完，小红书就有3篇内容了
2. 认真分析数据，找到你的优势方向
3. 基于数据制定下周计划，不要盲目继续

### 核心指标公式

- **点击率** = 浏览量 / 曝光量（平台数据里可以看到）
- **想要转化率** = 想要数 / 浏览量 × 100%
  - 正常范围：3%-10%
  - 低于3%：主图/标题/价格有问题
- **咨询转化率** = 咨询数 / 想要数 × 100%
  - 正常范围：20%-50%
  - 低了：详情页没说清楚，或者价格有问题
- **下单转化率** = 订单数 / 咨询数 × 100%
  - 正常范围：30%-60%
  - 低了：客服话术有问题，或者产品不够吸引人
- **收藏率**（小红书）= 收藏数 / 浏览量 × 100%
  - 正常范围：5%-15%
  - 高了说明内容有价值，容易被推荐
