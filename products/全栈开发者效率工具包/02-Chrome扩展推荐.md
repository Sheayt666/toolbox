## 开发工具类

### 1. React Developer Tools

- **功能介绍**：React 官方开发调试工具，可在浏览器中检查 React 组件树、查看 Props 和 State、实时调试。
- **适用场景**：React 应用开发调试、组件层级分析、性能分析
- **用户量**：400万+
- **评分**：4.6/5
- **亮点**：React 官方出品；支持 Components 和 Profiler 两个面板；可追踪组件渲染性能。

### 2. Vue.js devtools

- **功能介绍**：Vue.js 官方开发调试工具，支持检查组件、查看状态、时间旅行调试 Vuex/Pinia。
- **适用场景**：Vue 应用开发调试、状态管理调试
- **用户量**：200万+
- **评分**：4.7/5
- **亮点**：Vue 官方维护；支持 Vue 2 和 Vue 3；支持事件追踪和性能分析。

### 3. Redux DevTools

- **功能介绍**：Redux 状态管理调试工具，支持时间旅行调试、状态快照、Action 重放。
- **适用场景**：Redux 状态管理调试、复杂状态流追踪
- **用户量**：100万+
- **评分**：4.6/5
- **亮点**：时间旅行调试是核心亮点；支持导入导出状态快照；可与多种状态管理库配合。

### 4. JSON Viewer

- **功能介绍**：自动美化浏览器中的 JSON 输出，支持语法高亮、折叠展开、搜索过滤。
- **适用场景**：查看 API 返回的 JSON 数据、调试接口
- **用户量**：300万+
- **评分**：4.7/5
- **亮点**：自动识别 JSON 内容；支持多种主题；可折叠节点；支持 JSONPath 搜索。

### 5. Wappalyzer

- **功能介绍**：一键识别网站使用的技术栈，包括前端框架、后端语言、服务器、CMS、分析工具等。
- **适用场景**：技术调研、竞品分析、了解网站技术选型
- **用户量**：300万+
- **评分**：4.5/5
- **亮点**：识别准确率高；支持技术分类展示；可导出技术栈报告。

### 6. Postman Interceptor

- **功能介绍**：拦截浏览器请求并发送到 Postman，方便将实际请求导入 Postman 进行测试。
- **适用场景**：API 调试、快速将浏览器请求转为 Postman 集合
- **用户量**：100万+
- **评分**：4.3/5
- **亮点**：与 Postman 无缝集成；可拦截 Cookie 和请求头；支持同步请求集合。

### 7. Web Developer

- **功能介绍**：经典的 Web 开发工具箱，提供禁用 CSS、查看 Cookie、表单操作、图片信息等大量实用功能。
- **适用场景**：Web 前端开发调试、快速检查页面元素
- **用户量**：50万+
- **评分**：4.5/5
- **亮点**：功能全面的老牌工具；一键禁用 JS/CSS/图片；快速查看页面各种信息。

## 效率提升类

### 8. Vimium

- **功能介绍**：用 Vim 风格的键盘快捷键浏览网页，完全脱离鼠标操作，大幅提升浏览效率。
- **适用场景**：喜欢键盘操作的开发者、追求极致浏览效率
- **用户量**：60万+
- **评分**：4.8/5
- **亮点**：纯键盘操作；`f` 键点击链接、`j/k` 滚动、`o` 打开网址；可自定义快捷键。

### 9. Dark Reader

- **功能介绍**：为任意网站启用深色模式，保护眼睛，适合夜间工作。
- **适用场景**：夜间浏览、长时间使用电脑、深色主题爱好者
- **用户量**：500万+
- **评分**：4.7/5
- **亮点**：智能适配几乎所有网站；可调节亮度、对比度、棕褐色滤镜；支持网站白名单。

### 10. Tab Wrangler

- **功能介绍**：自动关闭长时间未使用的标签页，减少内存占用，保持浏览器清爽。
- **适用场景**：开太多标签页导致浏览器卡顿、内存不足
- **用户量**：20万+
- **评分**：4.6/5
- **亮点**：可配置自动关闭时间；关闭的标签页可在"标签页牧场"中找回；支持白名单。

### 11. OneTab

- **功能介绍**：一键将所有标签页合并为一个列表，节省高达 95% 的内存。
- **适用场景**：标签页过多、需要临时保存一批标签页
- **用户量**：300万+
- **评分**：4.5/5
- **亮点**：一键转换所有标签；可命名分组保存；支持导出导入；大幅释放内存。

### 12. uBlacklist

- **功能介绍**：在 Google 搜索结果中屏蔽指定网站，过滤低质量内容农场。
- **适用场景**：提升搜索质量、屏蔽垃圾网站
- **用户量**：20万+
- **评分**：4.8/5
- **亮点**：支持正则匹配；可订阅公共黑名单；支持 Google、Bing、DuckDuckGo 等搜索引擎。

## 设计辅助类

### 13. ColorZilla

- **功能介绍**：网页颜色拾取工具，可吸取页面上任意颜色，获取 HEX/RGB/HSL 值。
- **适用场景**：前端开发、UI 设计、颜色提取
- **用户量**：300万+
- **评分**：4.6/5
- **亮点**：吸管工具精准取色；支持颜色历史记录；内置调色板和渐变生成器。

### 14. WhatFont

- **功能介绍**：悬停即可查看网页使用的字体名称、字号、字重、颜色等信息。
- **适用场景**：前端开发、UI 设计、字体识别
- **用户量**：100万+
- **评分**：4.5/5
- **亮点**：操作简单，悬停即显示；支持查看字体服务来源（Google Fonts 等）。

### 15. Page Ruler Redux

- **功能介绍**：在网页上画出标尺，测量元素的像素尺寸和间距。
- **适用场景**：前端开发、UI 还原、精确测量页面元素
- **用户量**：20万+
- **评分**：4.4/5
- **亮点**：拖拽式测量；显示宽度、高度和位置；支持手动输入坐标。

### 16. PerfectPixel by WellDoneCode

- **功能介绍**：将设计稿半透明叠加在网页上，方便像素级还原对比。
- **适用场景**：像素级 UI 还原、前端切图开发
- **用户量**：10万+
- **评分**：4.5/5
- **亮点**：支持多种图片格式；可调整透明度和位置；支持多图层。

## 广告拦截与隐私类

### 17. uBlock Origin

- **功能介绍**：高效的广告拦截器，资源占用极低，拦截效果出色。
- **适用场景**：屏蔽网页广告、加速网页加载、保护隐私
- **用户量**：1000万+
- **评分**：4.7/5
- **亮点**：内存占用远低于同类广告拦截器；开源免费；支持自定义过滤规则。

### 18. SponsorBlock

- **功能介绍**：自动跳过 YouTube 视频中的赞助片段、自我介绍、订阅提醒等无关内容。
- **适用场景**：经常看 YouTube 技术视频、不想被赞助打断
- **用户量**：200万+
- **评分**：4.9/5
- **亮点**：众包式标记，准确率高；支持自定义跳过类别；开源透明。

### 19. ClearURLs

- **功能介绍**：自动移除 URL 中的跟踪参数（如 UTM 参数），保护隐私，简化网址。
- **适用场景**：注重隐私、分享干净链接
- **用户量**：30万+
- **评分**：4.7/5
- **亮点**：自动清理跟踪参数；支持自定义规则；轻量高效。

## 学习与资讯类

### 20. Zotero Connector

- **功能介绍**：一键保存网页、论文、书籍到 Zotero 文献管理库，自动抓取引用信息。
- **适用场景**：学术研究、技术学习、文献管理
- **用户量**：30万+
- **评分**：4.7/5

- **适用场景**：学英语、看技术视频顺便学英语

- **评分**：4.8/5

### 22. Notion Web Clipper

- **功能介绍**：一键将网页内容保存到 Notion，方便整理和归档技术文章。
- **适用场景**：知识管理、保存技术文章、收集素材
- **用户量**：50万+
- **评分**：4.4/5
- **亮点**：与 Notion 深度集成；可选择保存到指定页面；支持完整页面或选中文本。

## 其他实用工具

### 23. Tampermonkey（油猴）

- **功能介绍**：用户脚本管理器，可以安装各种脚本来增强网站功能，几乎无限可能。
- **适用场景**：自定义网站功能、自动化网页操作、增强特定网站体验
- **用户量**：1000万+
- **评分**：4.8/5
- **亮点**：扩展性极强；有大量现成的用户脚本（Greasy Fork 等）；支持自动更新脚本。

### 24. Feedbro

- **功能介绍**：RSS 阅读器，订阅博客和新闻网站，在浏览器内统一阅读。
- **适用场景**：订阅技术博客、聚合资讯源、信息获取
- **用户量**：10万+
- **评分**：4.7/5
- **亮点**：支持 RSS/Atom/FeedBurner；界面简洁；支持规则过滤和标签分类。

### 25. Save to Pocket

- **功能介绍**：一键保存文章到 Pocket，稍后阅读，支持离线阅读和跨设备同步。
- **适用场景**：遇到好文章但没时间读、统一管理阅读列表
- **用户量**：200万+
- **评分**：4.5/5
- **亮点**：一键保存；去除广告纯净阅读；多设备同步；支持标签分类。

## 扩展安装建议

### 必装基础款（5个）
1. uBlock Origin - 广告拦截，必装
2. Dark Reader - 深色模式，护眼
3. JSON Viewer - JSON 美化，开发必备
4. Wappalyzer - 技术栈识别
5. Vimium - 键盘高效浏览（可选）

### 前端开发者
- React Developer Tools / Vue.js devtools（按技术栈选择）
- ColorZilla - 取色
- WhatFont - 字体识别
- Web Developer - 综合调试

### 效率提升向
- OneTab - 标签页管理
- uBlacklist - 搜索结果过滤
- Tampermonkey - 自定义增强

> 提示：Chrome 扩展会占用内存和 CPU，安装过多会拖慢浏览器。只保留真正常用的，定期清理不用的扩展。
