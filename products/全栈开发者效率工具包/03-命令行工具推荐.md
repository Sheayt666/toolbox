## 文件处理类

### 1. fzf

- **功能介绍**：模糊查找工具，可用于查找文件、切换目录、搜索历史命令等，速度极快。
- **适用场景**：快速查找文件、模糊搜索历史命令、切换目录、选择 Git 分支
- **安装方式**：`brew install fzf`（macOS）/ `apt install fzf`（Linux）/ `scoop install fzf`（Windows）
- **GitHub Stars**：65k+
- **亮点**：超快的模糊搜索；可与 Vim/Neovim、tmux、zsh 等集成；交互式界面支持预览。
- **常用场景**：
  - `Ctrl+R` 模糊搜索命令历史
  - `Ctrl+T` 模糊查找文件并插入路径
  - `Alt+C` 模糊切换目录

### 2. ripgrep (rg)

- **功能介绍**：高性能的文本搜索工具，比 grep 快数倍，自动忽略 .gitignore 中的文件。
- **适用场景**：在代码库中搜索字符串、递归查找内容
- **安装方式**：`brew install ripgrep` / `apt install ripgrep` / `scoop install ripgrep`
- **GitHub Stars**：48k+
- **亮点**：速度极快（Rust 编写）；自动尊重 .gitignore；支持正则表达式；默认递归搜索。
- **常用命令**：
  - `rg "search_pattern"` 搜索内容
  - `rg -i "pattern"` 忽略大小写
  - `rg -t js "pattern"` 只搜索 js 文件

### 3. fd

- **功能介绍**：`find` 命令的现代替代品，更简单、更快、更人性化。
- **适用场景**：快速查找文件、按名称/类型/时间过滤文件
- **安装方式**：`brew install fd` / `apt install fd-find` / `scoop install fd`
- **GitHub Stars**：33k+
- **亮点**：语法比 find 简单得多；速度快（Rust 编写）；彩色输出；自动忽略 .gitignore。
- **常用命令**：
  - `fd "pattern"` 模糊查找文件名
  - `fd -e json` 查找所有 json 文件
  - `fd -t d "src"` 查找目录

### 4. bat

- **功能介绍**：带语法高亮和行号的 `cat` 命令替代品，支持 Git 集成显示修改。
- **适用场景**：查看文件内容、代码预览、代替 cat/less
- **安装方式**：`brew install bat` / `apt install bat` / `scoop install bat`
- **GitHub Stars**：50k+
- **亮点**：语法高亮支持大量语言；显示行号；Git 集成显示增删改；自动分页。
- **常用命令**：
  - `bat file.txt` 查看文件
  - `bat -n file.txt` 显示行号
  - `bat --style=plain file.md` 纯文本模式

### 5. exa

- **功能介绍**：`ls` 命令的现代替代品，彩色输出、支持 Git 状态、树状视图。
- **适用场景**：列出文件目录、查看文件详情、代替 ls
- **安装方式**：`brew install exa` / `apt install exa` / `scoop install exa`
- **GitHub Stars**：23k+
- **亮点**：彩色输出更易读；支持 Git 状态显示；树状视图；网格视图。
- **常用命令**：
  - `exa -l` 详细列表
  - `exa --tree` 树状视图
  - `exa --git` 显示 Git 状态

## Git 增强类

### 6. lazygit

- **功能介绍**：终端中的 Git 图形化客户端，用键盘操作，比命令行更直观，比 GUI 更快速。
- **适用场景**：日常 Git 操作、交互式暂存、合并冲突解决
- **安装方式**：`brew install lazygit` / `scoop install lazygit`
- **GitHub Stars**：50k+
- **亮点**：完全键盘操作；交互式暂存行/块；直观的分支图；合并冲突可视化解决。
- **常用操作**：
  - 空格键：暂存/取消暂存
  - `c`：提交
  - `p`：推送
  - `P`：拉取

### 7. gh (GitHub CLI)

- **功能介绍**：GitHub 官方命令行工具，可以在终端中直接操作 Issue、PR、Actions、仓库等。
- **适用场景**：GitHub 工作流、创建/查看 PR 和 Issue、查看 CI 状态
- **安装方式**：`brew install gh` / `scoop install gh`
- **GitHub Stars**：38k+
- **亮点**：GitHub 官方出品；无需切换浏览器；支持 PR 查看和合并；支持 Actions 状态查看。
- **常用命令**：
  - `gh pr list` 列出 PR
  - `gh pr create` 创建 PR
  - `gh pr checkout 123` 检出 PR
  - `gh issue create` 创建 Issue

### 8. delta

- **功能介绍**：语法高亮的 Git diff 查看器，让 diff 结果更易读。
- **适用场景**：查看 Git diff、代码变更对比
- **安装方式**：`brew install git-delta` / `scoop install delta`
- **GitHub Stars**：22k+
- **亮点**：语法高亮 diff；支持并排视图；行号显示；可定制化程度高。
- **配置方式**：
  ```
  git config --global core.pager delta
  git config --global delta.side-by-side true
  ```

## 开发效率类

### 9. tldr

- **功能介绍**：简化版的 man 手册，提供命令的常用示例，比 man 更实用。
- **适用场景**：快速查看命令用法、忘记参数时查阅
- **安装方式**：`npm install -g tldr` / `brew install tldr` / `scoop install tldr`
- **GitHub Stars**：48k+
- **亮点**：简洁实用，只给最常用的示例；支持多种语言；社区维护更新快。
- **常用命令**：
  - `tldr tar` 查看 tar 常用示例
  - `tldr ffmpeg` 查看 ffmpeg 常用示例
  - `tldr --update` 更新本地缓存

### 10. jq

- **功能介绍**：轻量级的 JSON 处理工具，可以在命令行中过滤、转换、格式化 JSON 数据。
- **适用场景**：处理 API 返回的 JSON、日志分析、数据转换
- **安装方式**：`brew install jq` / `apt install jq` / `scoop install jq`
- **GitHub Stars**：29k+
- **亮点**：JSON 处理的瑞士军刀；支持过滤、映射、转换；管道友好。
- **常用命令**：
  - `cat data.json | jq '.'` 格式化输出
  - `cat data.json | jq '.name'` 提取字段
  - `curl api.example.com | jq '.data[].id'` 提取数组字段

### 11. zoxide

- **功能介绍**：更智能的 `cd` 命令，根据访问频率自动跳转目录，告别 cd ../../..
- **适用场景**：快速在常用目录间跳转
- **安装方式**：`brew install zoxide` / `scoop install zoxide`
- **GitHub Stars**：17k+
- **亮点**：比 autojump/z 更快（Rust 编写）；模糊匹配；支持交互选择。
- **常用命令**：
  - `z foo` 跳转到名字包含 foo 的最常用目录
  - `zi` 交互式选择目录
  - `z foo bar` 多级匹配

### 12. httpie

- **功能介绍**：命令行 HTTP 客户端，比 curl 更友好，语法更简单，输出更美观。
- **适用场景**：测试 API、发送 HTTP 请求
- **安装方式**：`brew install httpie` / `pip install httpie` / `scoop install httpie`
- **GitHub Stars**：33k+
- **亮点**：语法比 curl 简单太多；彩色输出；自动格式化 JSON；支持表单和文件上传。
- **常用命令**：
  - `http GET example.com` GET 请求
  - `http POST api.example.com name=test` POST JSON
  - `http -f POST api.example.com file@file.txt` 上传文件

## 系统监控类

### 13. htop

- **功能介绍**：交互式的系统进程监控工具，比 top 更友好、更强大。
- **适用场景**：查看系统资源占用、监控进程、查找高占用进程
- **安装方式**：`brew install htop` / `apt install htop` / `scoop install htop`
- **GitHub Stars**：7k+
- **亮点**：彩色界面更直观；支持鼠标操作；树形进程视图；可直接操作进程。
- **常用操作**：
  - `F3` / `/` 搜索进程
  - `F9` 杀死进程
  - `F5` 树状视图
  - `F6` 排序

### 14. btop

- **功能介绍**：更现代化的系统资源监控工具，CPU、内存、磁盘、网络一目了然。
- **适用场景**：系统性能监控、服务器状态查看
- **安装方式**：`brew install btop` / `scoop install btop`
- **GitHub Stars**：15k+
- **亮点**：界面美观现代；支持鼠标；多种视图模式；显示详细的网络和磁盘信息。

- **适用场景**：DNS 查询、网络诊断

## 通用工具类

### 16. tmux

- **功能介绍**：终端复用器，可以在一个终端中创建多个窗口和面板，会话断开后可恢复。
- **适用场景**：远程开发、多任务并行、会话保持
- **安装方式**：`brew install tmux` / `apt install tmux` / `scoop install tmux`
- **GitHub Stars**：35k+
- **亮点**：会话持久化（远程连接断开不丢失）；分屏和窗口管理；可定制化程度极高。
- **常用操作**：
  - `Ctrl+b %` 垂直分屏
  - `Ctrl+b "` 水平分屏
  - `Ctrl+b c` 新建窗口
  - `Ctrl+b d` 脱离会话（后台运行）
  - `tmux attach` 恢复会话

### 17. ffmpeg

- **功能介绍**：强大的音视频处理工具，几乎可以处理所有音视频格式转换和编辑。
- **适用场景**：视频转码、音频提取、视频裁剪、格式转换
- **安装方式**：`brew install ffmpeg` / `scoop install ffmpeg`
- **官网**：ffmpeg.org
- **亮点**：功能极其强大；几乎支持所有格式；命令行批处理效率高。
- **常用命令**：
  - `ffmpeg -i input.mp4 output.webm` 格式转换
  - `ffmpeg -i video.mp4 -vn -acodec copy audio.aac` 提取音频
  - `ffmpeg -i input.mp4 -ss 00:01:00 -t 00:00:30 output.mp4` 截取片段

## 工具安装建议

### 必装基础款（5个）
1. **fzf** - 模糊搜索，命令行效率翻倍
2. **ripgrep (rg)** - 代码搜索必备
3. **bat** - 代替 cat，阅读体验大幅提升
4. **fd** - 代替 find，更简单更快
5. **tldr** - 查命令用法，告别 man 天书

### 开发者推荐
- **jq** - JSON 处理必备
- **httpie** - 比 curl 好用太多
- **lazygit** - Git 操作效率提升利器
- **gh** - GitHub 重度用户必备
- **zoxide** - 告别 cd ../../..

### 运维/服务器
- **htop / btop** - 系统监控
- **tmux** - 远程开发会话管理
- **delta** - 代码审查 diff 增强

> 提示：推荐使用包管理器统一安装和管理工具（macOS 用 Homebrew，Windows 用 Scoop/winget，Linux 用系统包管理器），方便升级和管理。
