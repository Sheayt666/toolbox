## 使用方式

1. 从 README 开始，了解整体结构
2. 根据自己的技术栈和需求，选择性阅读各模块
3. 挑选 2-3 个最痛点的工具先上手
4. 阅读 附赠-效率提升方法论.md，建立正确的工具使用观
5. 导入 VS Code 配置文件，快速获得最佳实践

> 建议：不要一次性安装所有工具。先解决最大的痛点，逐步引入，避免工具过载。
