## 在线工具类

### 1. CodePen (codepen.io)

- **功能介绍**：前端代码在线编辑和分享平台，可以实时预览 HTML/CSS/JS 效果。
- **适用场景**：前端原型验证、学习 CSS 技巧、分享代码示例、获取灵感
- **亮点**：
  - 全球最大的前端创意社区，每天有大量优秀作品
  - 支持预处理器（Sass、Less、Pug 等）
  - 可嵌入到博客和文档中
  - Collections 功能可以收藏整理
- **推荐用法**：遇到 CSS/动画难题先来搜搜，很多大神都在上面分享实现方案。

### 2. StackBlitz (stackblitz.com)

- **功能介绍**：在线 IDE，支持 Angular、React、Vue、Svelte 等主流框架，一键创建项目。
- **适用场景**：快速原型开发、在线学习、代码演示、Bug 复现
- **亮点**：
  - 启动速度极快，秒级创建项目
  - 支持完整的 npm 包安装
  - 可连接 GitHub 仓库
  - 支持 Node.js 后端环境（WebContainers）
- **推荐用法**：需要快速验证一个想法时，比本地建项目快 10 倍。

### 3. Replit (replit.com)

- **功能介绍**：在线编程平台，支持 50+ 种编程语言，可直接部署项目。
- **适用场景**：学习编程、快速原型、在线协作、教学
- **亮点**：
  - 支持语言非常全面
  - 内置数据库和部署功能
  - 多人实时协作编程
  - AI 辅助编程
- **推荐用法**：教别人编程时的好工具，不用配置环境，打开浏览器就能写。

### 4. JSON Crack (jsoncrack.com)

- **功能介绍**：JSON 数据可视化工具，将 JSON 数据转为直观的关系图。
- **适用场景**：理解复杂 JSON 结构、可视化 API 数据、调试数据结构
- **亮点**：
  - 自动生成节点关系图
  - 支持缩放、拖拽、搜索
  - 支持导入 JSON 文件和 URL
  - 可导出图片
- **推荐用法**：遇到嵌套很深的 JSON 结构时，用它一目了然。

### 5. RegExr (regexr.com)

- **功能介绍**：在线正则表达式测试和学习工具，实时匹配，可视化解释。
- **适用场景**：编写和调试正则表达式、学习正则语法
- **亮点**：
  - 实时匹配测试
  - 每个部分都有详细解释
  - 内置常用正则模式库
  - 支持 PCRE 和 JavaScript 两种模式
- **推荐用法**：写正则必备，比自己瞎试效率高太多。

### 6. Carbon (carbon.now.sh)

- **功能介绍**：代码截图美化工具，生成漂亮的代码图片，适合分享到社交媒体和文章中。
- **适用场景**：分享代码片段、制作教程配图、技术分享演示
- **亮点**：
  - 多种主题可选
  - 支持 100+ 语言语法高亮
  - 可调整窗口样式、背景、字体
  - 一键导出 PNG 或 SVG
- **推荐用法**：写技术博客时的代码配图，比直接截图好看太多。

## 学习资源类

### 7. MDN Web Docs (developer.mozilla.org)

- **功能介绍**：最权威的 Web 技术文档，涵盖 HTML、CSS、JavaScript、Web API 等。
- **适用场景**：查询 Web API 用法、学习前端基础知识、查阅标准规范
- **亮点**：
  - 内容权威准确，由 Mozilla 和社区维护
  - 每个 API 都有示例代码
  - 浏览器兼容性表格清晰
  - 中文翻译质量高
- **推荐用法**：前端开发的维基百科，遇到不确定的 API 直接查 MDN。

### 8. Can I Use (caniuse.com)

- **功能介绍**：查询前端技术的浏览器兼容性，支持 HTML、CSS、JS、SVG 等特性。
- **适用场景**：评估技术方案可行性、判断是否需要 polyfill、兼容性检查
- **亮点**：
  - 数据最全面的兼容性查询网站
  - 按浏览器版本细分
  - 显示全球使用率
  - 支持对比多个特性
- **推荐用法**：使用新特性之前先查一下，避免踩坑。

### 9. LeetCode (leetcode.com / leetcode.cn)

- **功能介绍**：算法刷题平台，包含 3000+ 道题目，支持多种编程语言。
- **适用场景**：算法练习、面试准备、编程能力提升
- **亮点**：
  - 题目质量高，分类清晰
  - 讨论区有大量优质题解
  - 模拟面试功能
  - 周赛/双周赛保持手感
- **推荐用法**：每天 1-2 道题保持手感，面试前集中刷高频题。

### 10. freeCodeCamp (freecodecamp.org / freecodecamp.cn)

- **功能介绍**：免费的编程学习平台，提供完整的前端、后端、数据科学等课程路径。
- **适用场景**：零基础入门、系统学习编程、获取认证
- **亮点**：
  - 完全免费，非盈利组织
  - 课程体系完整，从基础到进阶
  - 交互式学习，边学边练
  - 完成项目可获得认证
- **推荐用法**：零基础入门前端的最佳路径之一。

## 素材资源类

### 11. Unsplash (unsplash.com)

- **功能介绍**：高质量免费图片网站，所有图片可免费商用，无需署名。
- **适用场景**：项目配图、博客封面、PPT 素材、网站背景
- **亮点**：
  - 图片质量极高，摄影级别的素材
  - 完全免费，可商用
  - 搜索功能强大
  - API 支持程序化调用
- **推荐用法**：做项目需要占位图或配图时首选。

### 12. Iconify (iconify.design)

- **功能介绍**：统一的图标库平台，整合了 150+ 个图标集，超过 20 万个图标。
- **适用场景**：项目图标选型、快速获取图标、对比不同图标集
- **亮点**：
  - 图标数量极多，涵盖几乎所有主流图标库
  - 支持 SVG、React、Vue 等多种格式
  - 可在线预览和调整颜色
  - 提供统一的 API
- **推荐用法**：选图标先来这里搜，不用在各个图标库之间跳来跳去。

### 13. Figma Community (figma.com/community)

- **功能介绍**：Figma 社区资源平台，有大量免费的 UI 设计稿、组件库、插画、模板。
- **适用场景**：获取设计灵感、免费 UI 模板、组件库参考、学习设计
- **亮点**：
  - 资源极其丰富
  - 很多高质量免费资源
  - 可直接复制到自己的 Figma 文件中
  - 支持插件和模板
- **推荐用法**：做项目需要 UI 参考时，先去社区搜搜有没有现成的。

## 代码工具类

### 14. GitHub Gist (gist.github.com)

- **功能介绍**：GitHub 提供的代码片段分享服务，支持多文件、版本历史、评论。
- **适用场景**：分享代码片段、临时保存代码、协同讨论代码
- **亮点**：
  - 与 GitHub 账号打通
  - 支持私密和公开两种模式
  - 版本历史完整
  - 可嵌入到其他网站
- **推荐用法**：需要快速分享一段代码给别人时，比发文件方便太多。

### 15. Bundlephobia (bundlephobia.com)

- **功能介绍**：查询 npm 包的体积大小，包括压缩后和 gzip 后的体积。
- **适用场景**：评估依赖包大小、优化前端包体积、选型对比
- **亮点**：
  - 显示压缩前后体积对比
  - 展示依赖树
  - 可对比不同版本体积变化
  - 支持按体积搜索相似功能包
- **推荐用法**：安装新依赖前先查一下，避免引入体积过大的包。

### 16. npm trends (npmtrends.com)

- **功能介绍**：对比多个 npm 包的下载量趋势，帮助判断包的流行度和活跃度。
- **适用场景**：技术选型、对比同类包、评估包的活跃度
- **亮点**：
  - 同时对比多个包
  - 显示下载量趋势图
  - 展示 GitHub Stars 等信息
  - 可选择时间范围
- **推荐用法**：选技术方案时，用下载量趋势辅助判断社区活跃度。

## 参考文档类

### 17. DevDocs (devdocs.io)

- **功能介绍**：聚合了 100+ 种技术文档的离线文档站，统一的搜索和阅读体验。
- **适用场景**：查阅 API 文档、离线查阅文档、快速切换不同技术文档
- **亮点**：
  - 文档种类极全（前端、后端、DevOps 都有）
  - 支持离线使用（PWA）
  - 统一的搜索体验
  - 深色模式支持
- **推荐用法**：把它设为默认文档站，查 API 比翻官方文档快。

### 18. Excalidraw (excalidraw.com)

- **功能介绍**：手绘风格的在线绘图工具，可以画架构图、流程图、思维导图等。
- **适用场景**：画技术架构图、流程图、原型草图、团队协作画图
- **亮点**：
  - 手绘风格独特且美观
  - 操作简单上手快
  - 支持实时协作
  - 开源免费
- **推荐用法**：技术讨论时快速画图表达想法，比正经画图工具效率高。

## 网站使用建议

### 日常高频使用（每天都会用）
- **MDN Web Docs** - 查前端 API 必备
- **GitHub Gist** - 代码片段分享
- **Can I Use** - 兼容性查询

### 做项目时
- **CodePen / StackBlitz** - 快速原型验证
- **Bundlephobia / npm trends** - 依赖包选型
- **Iconify / Unsplash** - 素材资源

### 学习提升
- **LeetCode** - 算法练习
- **freeCodeCamp** - 系统学习
- **DevDocs** - 查阅文档

> 提示：把常用的网站放到浏览器书签栏，或者用 Vimium 快捷键快速访问。工具是辅助，关键还是要用起来。
