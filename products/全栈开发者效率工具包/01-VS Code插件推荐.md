## 效率提升类

### 1. GitHub Copilot

- **功能介绍**：由 GitHub 和 OpenAI 合作开发的 AI 代码补全工具，能根据上下文智能生成代码、函数、注释甚至整个文件。
- **适用场景**：日常编码、快速生成样板代码、编写测试用例、学习新语言/框架
- **安装量**：4000万+
- **评分**：4.8/5
- **亮点**：支持 Copilot Chat，可以直接在编辑器内对话式编程；支持行内补全和整段代码生成。

### 2. Copilot Chat

- **功能介绍**：GitHub Copilot 的对话式编程扩展，可在侧边栏与 AI 对话，解释代码、生成测试、重构代码、排查错误。
- **适用场景**：理解陌生代码、快速重构、错误排查、代码解释
- **安装量**：3500万+
- **评分**：4.7/5
- **亮点**：集成在 VS Code 内部，选中代码即可对话；支持 `/fix` `/explain` `/test` 等快捷指令。

### 3. Tabnine

- **功能介绍**：另一款 AI 代码补全工具，支持本地部署和多种 AI 模型，注重隐私保护。
- **适用场景**：对代码隐私有要求的企业用户、喜欢本地运行 AI 模型的开发者
- **安装量**：1200万+
- **评分**：4.4/5
- **亮点**：支持本地模型运行，代码不上传服务器；支持团队共享代码模式。

### 4. Path Intellisense

- **功能介绍**：自动补全文件路径，支持相对路径和绝对路径，大幅减少手动输入路径的错误。
- **适用场景**：前端项目中引用图片、组件、样式文件等
- **安装量**：1000万+
- **评分**：4.5/5
- **亮点**：轻量级，开箱即用；支持自定义文件扩展名过滤。

### 5. Auto Rename Tag

- **功能介绍**：自动重命名配对的 HTML/XML 标签，修改开始标签时结束标签同步更新。
- **适用场景**：HTML、JSX、TSX、Vue 模板开发
- **安装量**：1100万+
- **评分**：4.6/5
- **亮点**：支持多种文件格式；可配置自动重命名的标签类型。

### 6. Bracket Pair Colorizer 2 / VS Code 内置

- **功能介绍**：为匹配的括号对着色，让嵌套结构一目了然。现在 VS Code 已内置此功能。
- **适用场景**：处理复杂嵌套代码、快速定位括号匹配问题
- **安装量**：800万+（插件版）
- **评分**：4.7/5
- **亮点**：VS Code 已内置（`editor.bracketPairColorization.enabled`），无需额外安装插件。

### 7. indent-rainbow

- **功能介绍**：用不同颜色标记不同层级的缩进，让代码结构更清晰。
- **适用场景**：Python、YAML 等依赖缩进的语言；快速识别缩进层级
- **安装量**：400万+
- **评分**：4.5/5
- **亮点**：可自定义颜色和缩进错误提示；轻量不占用资源。

### 8. Better Comments

- **功能介绍**：让注释更有层次感，支持不同颜色标记 TODO、警告、疑问、重要信息等。
- **适用场景**：代码注释管理、团队协作中的代码沟通
- **安装量**：500万+
- **评分**：4.6/5
- **亮点**：支持 `// TODO` `// !` `// ?` `// *` 等多种注释类型；可自定义注释样式。

### 9. Todo Tree

- **功能介绍**：在侧边栏显示项目中所有的 TODO、FIXME、NOTE 等注释标签，支持点击跳转。
- **适用场景**：追踪待办事项、管理代码中的标记注释
- **安装量**：300万+
- **评分**：4.7/5
- **亮点**：支持自定义标签和图标；按标签分组显示；支持搜索过滤。

## 代码质量类

### 10. ESLint

- **功能介绍**：JavaScript/TypeScript 代码检查工具，自动发现并修复代码中的问题。
- **适用场景**：JS/TS 项目的代码规范检查、自动修复格式问题
- **安装量**：4500万+
- **评分**：4.6/5
- **亮点**：VS Code 官方维护；支持保存时自动修复；可与 Prettier 配合使用。

### 11. Prettier - Code formatter

- **功能介绍**：代码格式化工具，支持 JavaScript、TypeScript、CSS、HTML、JSON、Markdown 等多种语言。
- **适用场景**：统一团队代码风格、保存时自动格式化
- **安装量**：5000万+
- **评分**：4.7/5
- **亮点**：配置简单；支持多种语言；与 ESLint 无缝配合。

### 12. SonarLint

- **功能介绍**：静态代码分析工具，实时检测代码中的 Bug、漏洞和代码异味。
- **适用场景**：提升代码质量、发现潜在 Bug、安全漏洞检测
- **安装量**：600万+
- **评分**：4.5/5
- **亮点**：支持多种语言；提供详细的问题解释和修复建议；可与 SonarQube 集成。

### 13. Code Spell Checker

- **功能介绍**：代码拼写检查器，识别变量名、注释、字符串中的拼写错误。
- **适用场景**：英文代码编写、减少命名拼写错误
- **安装量**：300万+
- **评分**：4.6/5
- **亮点**：支持驼峰式和下划线命名的拼写检查；可添加自定义词典；轻量不干扰。

## 调试与运行类

### 19. Code Runner

- **功能介绍**：一键运行代码片段，支持 C、C++、Java、Python、JS、Go 等 40+ 种语言。
- **适用场景**：快速测试代码片段、学习新语言时运行小例子
- **安装量**：1500万+
- **评分**：4.5/5
- **亮点**：支持右键运行、快捷键运行；可自定义运行命令；支持输出到终端。

### 20. Thunder Client

- **功能介绍**：轻量级 REST API 客户端，类似 Postman，但集成在 VS Code 内部。
- **适用场景**：API 开发和测试、替代 Postman
- **安装量**：300万+
- **评分**：4.7/5
- **亮点**：轻量快速；界面简洁；支持集合管理和环境变量；无需离开编辑器。

### 21. REST Client

- **功能介绍**：另一种风格的 API 测试工具，用 `.http` 文件定义请求，支持直接在编辑器中发送。
- **适用场景**：喜欢纯文本方式定义 API 请求、需要版本控制 API 文档的团队
- **安装量**：200万+
- **评分**：4.6/5
- **亮点**：请求定义可版本控制；支持变量和环境；支持 GraphQL。

## Git 与版本控制类

### 22. GitLens

- **功能介绍**：Git 超级增强插件，在行内显示代码最后修改人和时间，提供丰富的 Git 历史浏览功能。
- **适用场景**：团队协作、代码审查、了解代码变更历史
- **安装量**：3500万+
- **评分**：4.8/5
- **亮点**：行内 Blame 信息；丰富的 Git 历史视图；支持搜索和对比；功能全面但可配置。

### 23. Git Graph

- **功能介绍**：可视化 Git 提交历史图，清晰展示分支、合并、标签等信息。
- **适用场景**：理解复杂的 Git 分支结构、可视化 Git 历史
- **安装量**：600万+
- **评分**：4.8/5
- **亮点**：图形化分支历史；支持右键操作提交和分支；搜索过滤功能强大。

### 24. Git History

- **功能介绍**：查看文件的 Git 历史，支持对比不同版本、查看提交详情。
- **适用场景**：查看单个文件的修改历史、对比文件变更
- **安装量**：400万+
- **评分**：4.6/5
- **亮点**：文件历史视图清晰；支持跨版本对比；搜索提交信息。

### 25. Error Lens

- **功能介绍**：在行内直接显示错误和警告信息，无需悬停查看，让问题一目了然。
- **适用场景**：快速发现代码错误、实时了解问题严重程度
- **安装量**：200万+
- **评分**：4.6/5
- **亮点**：错误信息直接显示在代码行尾；支持多种诊断源；可配置显示样式。

## 其他实用工具

### 30. Live Server

- **功能介绍**：启动本地开发服务器，支持实时刷新，修改文件后浏览器自动更新。
- **适用场景**：前端静态页面开发、快速预览 HTML/CSS/JS
- **安装量**：5000万+
- **评分**：4.6/5
- **亮点**：一键启动；实时热重载；支持多设备同步预览。

### 31. Draw.io Integration

- **功能介绍**：在 VS Code 中直接编辑 Draw.io (diagrams.net) 图表文件。
- **适用场景**：绘制架构图、流程图、UML 图
- **安装量**：100万+
- **评分**：4.7/5
- **亮点**：无需离开编辑器；支持 `.drawio` 和 `.drawio.svg` 格式；图表可版本控制。

### 32. Markdown All in One

- **功能介绍**：Markdown 编辑增强，提供快捷键、自动预览、目录生成、数学公式等功能。
- **适用场景**：编写 README、技术文档、笔记
- **安装量**：400万+
- **评分**：4.7/5
- **亮点**：快捷键丰富；自动生成目录；支持 LaTeX 数学公式；表格格式化。

### 33. Remote - SSH

- **功能介绍**：通过 SSH 连接远程服务器，在本地 VS Code 中直接编辑远程文件和运行命令。
- **适用场景**：远程开发、服务器管理、云服务器开发
- **安装量**：2000万+
- **评分**：4.7/5
- **亮点**：微软官方出品；体验如同本地开发；支持端口转发；与其他 Remote 扩展配合使用。

### 34. Docker

- **功能介绍**：Docker 官方扩展，提供容器管理、镜像管理、Docker Compose 支持等功能。
- **适用场景**：容器化开发、Docker 日常操作
- **安装量**：1500万+
- **评分**：4.6/5
- **亮点**：Docker 官方维护；可视化容器和镜像管理；支持 Docker Compose；集成调试。

### 35. Project Manager

- **功能介绍**：项目管理器，快速在多个项目间切换，支持标记收藏项目。
- **适用场景**：同时维护多个项目、需要频繁切换项目的开发者
- **安装量**：200万+
- **评分**：4.7/5
- **亮点**：一键切换项目；支持标签分类；可从 Git 仓库自动检测项目。

## 插件安装建议

### 必装基础款（5个）
1. GitHub Copilot - AI 编码助手
2. ESLint - 代码检查
3. Prettier - 代码格式化
4. GitLens - Git 增强
5. Material Icon Theme - 文件图标

### 按技术栈选择
- **前端**：Auto Rename Tag + Path Intellisense + Live Server
- **React**：ES7+ React Snippets + Error Lens
- **Vue**：Vue - Official (Volar)
- **Python**：Python + Pylance
- **Go**：Go 官方扩展

### 按需求选择
- **API 开发**：Thunder Client / REST Client
- **远程开发**：Remote - SSH
- **容器开发**：Docker
- **文档编写**：Markdown All in One + Draw.io Integration

> 提示：不要一次性安装所有插件。按需安装，用不上的及时卸载，保持编辑器轻量流畅。
