# 模板18：饮食管理日志

> 记录每一餐，吃出健康好身材

---

## 一、模板简介

饮食管理日志是一套科学的饮食记录与分析工具。它帮你记录每天吃了什么、吃了多少、吃得怎么样，通过数据分析发现饮食习惯中的问题，逐步建立健康的饮食方式，吃出健康好身材。

## 二、适用人群

- 想要减肥/增肌需要控制饮食的人
- 关注健康饮食的生活方式追求者
- 有特定饮食需求的人（如控糖、低卡等）
- 想要改善饮食习惯的人
- 健身人群的饮食配合记录

## 三、模板结构设计

### 整体架构

```
饮食管理日志（主页面）
├── 🍽️ 饮食记录（数据库 - 每餐记录）
├── 📊 每日汇总（数据库 - 每日营养统计）
├── 🥗 食物库（数据库 - 常见食物营养数据）
├── 🎯 饮食目标（目标设定）
├── 💧 饮水记录（喝水打卡）
├── 📈 体重追踪（关联健身记录）
└── 📋 食谱收藏（数据库）
```

### 饮食管理闭环

- 设定目标 → 记录饮食 → 统计分析 → 发现问题 → 调整饮食 → 达成目标

## 六、使用说明

### 第一步：设定饮食目标

1. 确定你的饮食目标：减肥、增肌、保持健康、改善皮肤...
2. 计算每日所需热量
   - 减肥：基础代谢 × 0.8
   - 维持：基础代谢 × 1.0
   - 增肌：基础代谢 × 1.2
3. 设定三大营养素比例
   - 减肥：蛋白30%、碳水40%、脂肪30%
   - 增肌：蛋白30%、碳水50%、脂肪20%
4. 设定每日饮水目标（建议2000ml左右）

### 第二步：完善食物库

1. 把你常吃的食物添加到食物库
2. 填写每种食物的营养数据
3. 标记健康等级（绿灯/黄灯/红灯）
4. 越完善记录越准确

### 第三步：记录每一餐

1. 每次吃饭后及时记录
2. 拍照记录（可选但推荐，更有真实感）
3. 估算热量和营养
4. 记录饱腹感和吃饭心情
5. 标记健康程度

### 第四步：每日汇总

1. 晚上汇总当天的饮食
2. 统计总热量和营养摄入
3. 和目标对比，看看是否达标
4. 给当天的饮食打个分
5. 记录当天体重（可选）

### 第五步：定期回顾调整

1. **每周**：回顾本周饮食情况，找出问题
2. **每月**：看体重和体脂变化，调整目标
3. **持续优化**：逐步改善饮食习惯

## 七、最佳实践

1. **及时记录** - 吃完就记，不然很容易忘
2. **拍照记录** - 拍照比文字更直观，也更有成就感
3. **诚实记录** - 不要因为吃了不健康的就不记，真实记录才能发现问题
4. **不要追求精确** - 估算就好，不必精确到每一大卡
5. **关注整体** - 看整体饮食结构，不要纠结某一顿
6. **循序渐进** - 不要一下子改变太多，逐步调整
7. **允许弹性** - 偶尔大吃一顿没关系，长期坚持才重要
8. **食物多样** - 保证食物多样性，营养才均衡
9. **多喝水** - 很多时候饿其实是渴
10. **享受美食** - 健康饮食不是苦行僧，享受食物本身

## 💡 健康饮食指南
### 膳食宝塔
1. **谷薯类**：250-400g/天
2. **蔬菜水果**：蔬菜300-500g，水果200-350g
3. **畜禽鱼蛋奶**：120-200g/天
4. **大豆坚果**：适量
5. **油盐糖**：少油少盐少糖

### 健康饮食原则
1. **食物多样** - 每天吃12种以上食物
2. **均衡营养** - 碳水、蛋白、脂肪都要有
3. **多吃蔬菜** - 每餐都要有蔬菜
4. **优质蛋白** - 鱼禽肉蛋奶豆
5. **全谷物** - 用全谷物替代部分精米白面
6. **少盐少油** - 清淡饮食
7. **控糖限酒** - 少喝含糖饮料
8. **吃动平衡** - 吃动结合，健康体重

### 减脂饮食小贴士
1. 制造热量缺口，但不要节食
2. 保证蛋白质摄入，减少肌肉流失
3. 多吃蔬菜，增加饱腹感
4. 选择低GI食物，稳定血糖
5. 少吃深加工食品
6. 细嚼慢咽，吃慢点
7. 规律三餐，不要跳餐
8. 多喝水，有时候渴了以为是饿了
