# 模板02：每日复盘模板

> 每日三省吾身，持续迭代进化

---

## 一、模板简介

每日复盘模板是基于PDCA循环和反思日记理念设计的Notion模板。它帮助你建立每日反思的习惯，通过记录、复盘、改进的循环，让每一天都有进步，持续迭代成为更好的自己。

## 二、适用人群

- 想要养成复盘习惯的自我成长者
- 经常感觉一天忙忙碌碌却没收获的人
- 希望提升自我认知的职场人士
- 践行终身学习理念的人

## 三、模板结构设计

### 整体架构

```
每日复盘系统（主页面）
├── 🌅 今日复盘（快捷入口）
├── 📓 复盘日记库（数据库）
├── 📊 月度复盘汇总（汇总页面）
├── 🏆 成就记录（数据库）
├── 🎯 习惯追踪（数据库）
└── 💡 灵感与想法（数据库）
```

## 四、属性字段设计

### 1. 复盘日记数据库

| 字段名 | 字段类型 | 用途说明 |
|-------|---------|---------|
| 日期 | 标题 | 格式：2026-07-08 |
| 星期 | 公式 | 自动计算星期几 |
| 今日心情 | 单选 | 超棒、不错、一般、糟糕、很差 |
| 精力值 | 评分 | 1-5颗星 |
| 效率值 | 评分 | 1-5颗星 |
| 满意度 | 评分 | 1-5颗星 |
| 今日关键词 | 多选 | 工作、学习、运动、社交、休息、旅行、娱乐... |
| 早起时间 | 日期 | 包含时间 |
| 睡觉时间 | 日期 | 包含时间 |
| 睡眠时长 | 公式 | 自动计算睡眠小时数 |
| 运动情况 | 单选 | 有运动、无运动 |
| 运动类型 | 多选 | 跑步、健身、瑜伽、游泳、球类... |
| 运动时长 | 数字 | 分钟 |
| 阅读时长 | 数字 | 分钟 |
| 学习时长 | 数字 | 小时 |
| 工作时长 | 数字 | 小时 |
| 今日三事 | 复选框 | 今日最重要的3件事 |
| 三事完成数 | 公式 | 已完成的数量 |
| 三事完成率 | 公式 | 完成数/3 |
| 关联月度复盘 | 关联 | 关联到月度复盘 |
| 天气 | 文本 | 可选记录 |
| 标签 | 多选 | 自定义标签 |

**星期计算公式：**
```
formatDate(prop("日期"), "dddd")
```

**睡眠时长计算公式：**
```
round(dateBetween(prop("睡觉时间"), prop("早起时间"), "minutes") / 60 * 10) / 10
```

## 六、使用说明

### 每日复盘流程（建议晚上21:00-22:00）

1. **打开今日复盘** - 点击主页面的「今日复盘」按钮
2. **填写基础信息** - 心情、精力、效率、满意度评分
3. **回顾今日三事** - 勾选完成情况
4. **记录时间分配** - 工作、学习、运动、阅读时长
5. **填写核心复盘内容** - 按照模板结构填写
6. **添加成就记录** - 如果今天有值得记录的成就
7. **打卡习惯** - 在习惯追踪中勾选完成的习惯
8. **规划明天** - 写下明天最重要的3件事

## 七、最佳实践

1. **固定时间复盘** - 建议每天晚上固定时间复盘，形成习惯
2. **诚实面对自己** - 复盘不是给自己打分，而是真实记录和反思
3. **关注进步而非完美** - 不必每天都写很长，关键是坚持
4. **善用模板** - 可以创建模板按钮，一键生成当日复盘
5. **定期回顾** - 每周、每月回顾复盘记录，发现规律
6. **多写正向内容** - 适当关注做得好的地方，给自己积极反馈
7. **关联其他模板** - 和任务追踪、读书笔记等模板联动
