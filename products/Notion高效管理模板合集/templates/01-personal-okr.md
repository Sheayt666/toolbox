# 模板01：个人OKR系统

> 目标拆解与进度追踪，让梦想落地

---

## 一、模板简介

个人OKR系统是基于OKR（Objectives and Key Results，目标与关键成果）方法论设计的Notion模板。它帮助你将宏大的人生愿景拆解为可执行的年度、季度、月度目标，并通过关键结果量化进度，让每一个目标都能被追踪、被实现。

## 二、适用人群

- 有明确人生目标但不知道如何落地的人
- 想要系统规划个人成长的职场人士
- 经常制定目标但难以坚持的拖延症患者
- 希望用数据驱动自我成长的效率爱好者

## 三、模板结构设计

### 整体架构

```
个人OKR系统（主页面）
├── 🎯 愿景板（顶层页面）
├── 📅 年度OKR（数据库）
├── 📆 季度OKR（数据库）
├── 🗓️ 月度OKR（数据库）
├── ✅ 本周关键行动（数据库）
├── 📊 进度仪表盘（汇总页面）
└── 📝 复盘记录（数据库）
```

### 数据库关系图

- 年度OKR → 一对多 → 季度OKR
- 季度OKR → 一对多 → 月度OKR
- 月度OKR → 一对多 → 本周关键行动
- 所有层级通过「关联」属性互相联动

## 四、属性字段设计

### 1. 年度OKR数据库

| 字段名 | 字段类型 | 用途说明 |
|-------|---------|---------|
| 目标名称 | 标题 | 年度目标的简短描述 |
| 目标描述 | 文本 | 目标的详细说明和背景 |
| 年度 | 单选 | 2024、2025、2026... |
| 状态 | 单选 | 进行中、已完成、已暂停、已放弃 |
| 优先级 | 单选 | P0（最高）、P1、P2、P3 |
| 类别 | 多选 | 职业发展、财务自由、健康管理、人际关系、个人成长、家庭生活 |
| 开始日期 | 日期 | 目标开始时间 |
| 结束日期 | 日期 | 目标截止时间 |
| 进度 | 公式 | 自动计算：已完成KR数 / 总KR数 |
| 关联季度OKR | 关联 | 关联到季度OKR数据库 |
| 关键结果1 | 文本 | KR1描述 + 目标值 |
| 关键结果2 | 文本 | KR2描述 + 目标值 |
| 关键结果3 | 文本 | KR3描述 + 目标值 |
| 关键结果4 | 文本 | KR4描述 + 目标值（可选） |
| 标签 | 多选 | 自定义标签 |
| 封面图 | 文件 | 目标的视觉化封面 |

**进度公式：**
```
if(prop("状态") == "已完成", 100, round(toNumber(length(filter(prop("关联季度OKR"), (p) => p.current.data["状态"] == "已完成"))) / toNumber(length(prop("关联季度OKR"))) * 100) / 100)
```

| 主要风险 | 文本 | 可能影响目标达成的风险 |
| 需要的支持 | 文本 | 需要哪些资源或帮助 |
| 开始日期 | 日期 | 季度开始日期 |

### 3. 月度OKR数据库

| 字段名 | 字段类型 | 用途说明 |

## 六、使用说明

### 第一步：设定年度目标

1. 在「年度OKR」数据库中创建新条目
2. 填写目标名称和描述
3. 设置类别、优先级、时间范围
4. 写下3-4个关键结果（KR），确保每个KR都是可量化的
5. 上传一张有激励性的封面图

**好的OKR示例：**
- O：提升职业竞争力，实现薪资增长30%
- KR1：完成3个核心技能认证课程
- KR2：主导2个重要项目并获得好评
- KR3：建立行业人脉，结识50位同行
- KR4：通过面试，薪资涨幅达到30%

### 第二步：拆解季度目标

1. 每个年度目标拆解为4个季度目标
2. 每个季度聚焦1-2个年度目标的推进
3. 为季度目标设定具体的关键结果
4. 定期更新信心指数

### 第三步：落实月度计划

1. 月初将季度目标拆解为本月行动项
2. 每个行动项都要具体可执行
3. 使用复选框追踪完成情况
4. 月末进行复盘

### 第四步：每周回顾

1. 周日晚上规划下周关键行动
2. 每天早上查看今日待办
3. 完成后勾选状态
4. 周五下午进行周回顾

## 七、最佳实践

1. **目标不宜过多** - 年度目标3-5个最佳，季度目标2-3个，月度目标1-2个
2. **KR必须可量化** - 避免"学习英语"这种模糊表述，改为"雅思成绩达到7分"
3. **定期复盘** - 每周小复盘，每月中复盘，每季度大复盘
4. **灵活调整** - OKR不是一成不变的，根据实际情况调整目标和KR
5. **可视化激励** - 给每个目标配上有感染力的封面图，增加动力
6. **关联其他模板** - 将行动项关联到任务追踪系统，形成闭环
