# 模板08：会议纪要模板

> 高效会议从记录开始，决议可追踪

---

## 一、模板简介

会议纪要模板是一套系统化的会议管理工具。它不仅帮你记录会议内容，更重要的是通过标准化的会议流程、明确的行动项追踪和会后跟进机制，让每一次会议都高效有成果，彻底告别"开会没结果，会后没人跟"的困境。

## 二、适用人群

- 经常组织或参加会议的职场人士
- 想要提升会议效率的团队管理者
- 需要记录和追踪会议决议的项目负责人
- 希望建立会议文化的创业团队
- 经常开会但感觉效率低下的人

## 三、模板结构设计

### 整体架构

```
会议纪要系统（主页面）
├── 📅 会议日历（日历视图）
├── 📝 会议数据库（核心数据库）
├── ✅ 行动项追踪（数据库 - 从会议中提取）
├── 📋 会议模板库（不同类型的会议模板）
└── 📊 会议统计（数据汇总）
```

### 会议全流程管理

1. **会前** - 准备议程、邀请参会人、预读材料
2. **会中** - 记录讨论、记录决议、分配行动项
3. **会后** - 发送纪要、追踪行动项、评估会议效果

## 四、属性字段设计

### 1. 会议数据库

| 字段名 | 字段类型 | 用途说明 |
|-------|---------|---------|
| 会议主题 | 标题 | 会议的主题/名称 |
| 会议类型 | 单选 | 周会、月会、项目会、评审会、头脑风暴、1on1、培训、其他 |
| 状态 | 单选 | 计划中、已确认、进行中、已完成、已取消 |
| 日期 | 日期 | 会议日期 |
| 开始时间 | 日期 | 含具体时间 |
| 结束时间 | 日期 | 含具体时间 |
| 会议时长 | 公式 | 自动计算时长（分钟） |
| 主持人 | 人员 | 会议主持人 |
| 参会人 | 人员 | 所有参会人员 |
| 会议地点 | 文本 | 线下地点或线上链接 |
| 所属项目 | 关联 | 关联到项目管理（可选） |
| 优先级 | 单选 | 高、中、低 |
| 会议效果 | 评分 | 1-5颗星（会后填写） |
| 关联行动项 | 关联 | 关联到行动项数据库 |
| 行动项数量 | 公式 | 关联的行动项数量 |
| 已完成行动项 | 公式 | 已完成的行动项数量 |
| 行动项完成率 | 公式 | 已完成 / 总数 |
| 标签 | 多选 | 自定义标签 |
| 附件 | 文件 | 会议相关材料 |

**会议时长计算公式：**
```
dateBetween(prop("结束时间"), prop("开始时间"), "minutes")
```

| 字段名 | 字段类型 | 用途说明 |
|-------|---------|---------|
| 行动项 | 标题 | 具体行动描述 |
| 来源会议 | 关联 | 关联到会议数据库 |
| 负责人 | 人员 | 谁来做 |
| 状态 | 单选 | 待办、进行中、已完成、已延期、已取消 |
| 优先级 | 单选 | 高、中、低 |
| 截止日期 | 日期 | 需要完成的时间 |
| 完成日期 | 日期 | 实际完成时间 |
| 所属项目 | 关联 | 关联到项目（可选） |
| 描述 | 文本 | 详细说明 |
| 交付物 | 文本 | 需要交付什么 |

## 五、视图设计

### 会议数据库视图

1. **日历视图** - 最直观，查看会议安排
2. **列表视图（按时间倒序）** - 浏览历史会议
3. **看板视图（按状态）** - 计划中、已确认、进行中、已完成、已取消
4. **看板视图（按类型）** - 按会议类型分组
5. **本周会议视图** - 过滤本周的会议
6. **待跟进视图** - 行动项未全部完成的会议

### 行动项视图

1. **看板视图（按状态）** - 待办、进行中、已完成、已延期
2. **列表视图（按截止日期排序）** - 快到期的在前
3. **按负责人分组视图** - 每个人的行动项一目了然
4. **按会议分组视图** - 每个会议产生的行动项
5. **我的行动项视图** - 过滤器：负责人是我
6. **逾期行动项视图** - 已过期但未完成的

## 六、使用说明

### 第一步：会前准备

1. 创建新的会议记录
2. 填写会议主题、类型、时间、地点
3. 添加参会人
4. 准备会议议程（按顺序列出讨论议题）
5. 上传会议材料（可选）
6. 提前发送会议邀请和议程

### 第二步：会中记录

1. 更新会议状态为「进行中」
2. 按议程逐项讨论
3. 记录关键讨论要点
4. 记录形成的决议
5. 每个行动项都要明确：做什么、谁来做、什么时候完成
6. 控制会议时间，确保议程完成

### 第三步：会后跟进

1. 会议结束后24小时内整理完纪要
2. 更新会议状态为「已完成」
3. 给会议效果打分
4. 提取所有行动项到行动项数据库
5. 发送会议纪要给所有参会人
6. 定期追踪行动项完成情况

### 第四步：行动项追踪

1. 每周查看未完成的行动项
2. 提醒负责人更新进度
3. 已完成的及时更新状态
4. 延期的要说明原因并重新安排

## 七、最佳实践

1. **无议程不开会** - 每次会议都要有明确的议程
2. **控制参会人数** - 只邀请必要的人，人多效率低
3. **准时开始准时结束** - 尊重每个人的时间
4. **聚焦主题** - 跑题的内容先记下来，会后再讨论
5. **明确行动项** - 每个行动项必须有负责人和截止时间
6. **及时发送纪要** - 会后24小时内发送，趁热打铁
7. **追踪到底** - 行动项不追踪等于没说
8. **定期回顾** - 评估会议效果，持续改进
9. **能不开会就不开** - 能用文字沟通的就别开会
10. **站会要站着** - 每日站会真的要站着开，控制在15分钟内

- 行动项要追踪到底，定期回顾
- 会议效果要评估，持续改进
