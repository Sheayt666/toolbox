# 模板04：财务管理系统

> 收支一目了然，实现财务自由第一步

---

## 一、模板简介

财务管理系统是一套完整的个人财务追踪与分析工具。它不仅帮你记录每一笔收支，更重要的是通过多维度的数据分析，让你清晰了解自己的财务状况，制定合理的预算，逐步实现财务自由的目标。

## 二、适用人群

- 想要摆脱月光状态的年轻人
- 计划存钱买房/买车/旅行的储蓄者
- 希望了解钱花在哪里的人
- 追求财务自由的投资者
- 需要管理多账户的人

## 三、模板结构设计

### 整体架构

```
财务管理系统（主页面）
├── 💰 收支记录（核心数据库）
├── 🏦 账户管理（数据库）
├── 📊 财务仪表盘（汇总页面）
├── 📈 预算管理（数据库）
├── 💳 债务管理（数据库）
├── 📋 月度财务报告（汇总页面）
└── 🎯 财务目标（数据库）
```

### 核心逻辑

- 每笔收支记录关联到具体账户和分类
- 账户实时计算余额
- 预算与实际支出对比分析
- 多维度统计：月度、分类、趋势

## 四、属性字段设计

### 1. 收支记录数据库

| 字段名 | 字段类型 | 用途说明 |
|-------|---------|---------|
| 记录名称 | 标题 | 简短描述这笔收支 |
| 类型 | 单选 | 收入、支出、转账 |
| 金额 | 数字 | 收支金额（收入为正，支出为正，单独用类型区分） |
| 分类 | 单选 | 餐饮、交通、购物、住房、娱乐、医疗、教育、工资、投资收益... |
| 子分类 | 单选 | 分类下的细分类别 |
| 账户 | 关联 | 关联到账户数据库 |
| 日期 | 日期 | 发生日期 |
| 月份 | 公式 | 自动提取年月 |
| 支付方式 | 单选 | 现金、微信、支付宝、银行卡、信用卡 |
| 备注 | 文本 | 详细说明 |
| 是否必要 | 单选 | 必要支出、非必要支出 |
| 标签 | 多选 | 自定义标签 |
| 关联预算 | 关联 | 关联到预算项 |
| 创建时间 | 创建时间 | 自动记录 |

**月份计算公式：**
```
formatDate(prop("日期"), "YYYY-MM")
```

### 2. 账户管理数据库

| 字段名 | 字段类型 | 用途说明 |
|-------|---------|---------|
| 账户名称 | 标题 | 账户名称 |
| 账户类型 | 单选 | 现金、储蓄卡、信用卡、支付宝、微信、股票账户、基金账户、其他投资 |
| 初始余额 | 数字 | 开始记账时的余额 |
| 当前余额 | 公式 | 自动计算：初始余额 + 收入 - 支出 + 转入 - 转出 |
| 币种 | 单选 | 人民币、美元、港币... |
| 状态 | 单选 | 正常、已注销、冻结 |
| 开户行/平台 | 文本 | 银行或平台名称 |
| 卡号/账号后四位 | 文本 | 便于识别 |
| 账单日 | 数字 | 信用卡账单日（仅信用卡） |
| 还款日 | 数字 | 信用卡还款日（仅信用卡） |
| 信用额度 | 数字 | 信用卡额度（仅信用卡） |
| 备注 | 文本 | 其他说明 |
| 关联收支记录 | 关联 | 关联到收支记录 |

### 3. 预算管理数据库

| 字段名 | 字段类型 | 用途说明 |
|-------|---------|---------|
| 预算项目 | 标题 | 预算名称 |
| 分类 | 单选 | 对应收支分类 |
| 预算金额 | 数字 | 本月预算金额 |
| 实际支出 | 汇总 | 从收支记录汇总 |
| 剩余预算 | 公式 | 预算金额 - 实际支出 |
| 使用率 | 公式 | 实际支出 / 预算金额 |
| 状态 | 公式 | 正常、警告、超支 |
| 月份 | 单选 | 适用月份 |
| 备注 | 文本 | 预算说明 |

**使用率公式：**
```
round(prop("实际支出") / prop("预算金额") * 100) / 100
```

**状态公式：**
```
if(prop("使用率") >= 1, "🔴 超支", if(prop("使用率") >= 0.8, "🟡 警告", "🟢 正常"))
```

### 4. 财务目标数据库

| 字段名 | 字段类型 | 用途说明 |

| 目标名称 | 标题 | 财务目标描述 |

| 备注 | 文本 | 目标说明 |

## 六、使用说明

### 第一步：设置账户

1. 在账户管理中添加你所有的账户
2. 填写每个账户的初始余额
3. 按账户类型分类管理

### 第二步：设定预算

1. 每月初设置本月各分类的预算
2. 根据历史支出数据合理设定
3. 重点关注容易超支的分类

### 第三步：记录每笔收支

1. 每次消费后及时记录（建议用手机端快速录入）
2. 选择正确的分类和账户
3. 适当添加备注，便于后续分析
4. 转账也需要记录（从A账户转到B账户）

### 第四步：定期查看分析

1. **每日**：快速浏览今日收支
2. **每周**：查看本周支出情况，及时调整
3. **每月**：深度分析本月财务状况
   - 总收入 vs 总支出
   - 各分类支出占比
   - 预算执行情况
   - 储蓄率计算
4. **每年**：年度财务总结，制定下一年目标

### 第五步：追踪财务目标

1. 设定短期、中期、长期财务目标
2. 每月更新目标进度
3. 根据进度调整储蓄计划

## 七、最佳实践

1. **及时记录** - 最好消费后立即记录，避免遗忘
2. **分类准确** - 准确的分类是分析的基础
3. **固定复盘** - 每月固定时间做财务复盘
4. **先存后花** - 工资到账先存一部分，再花剩下的
5. **关注储蓄率** - 储蓄率 = （收入 - 支出）/ 收入，目标>30%
6. **预算弹性** - 预算不是一成不变的，可以灵活调整
7. **区分必要和非必要支出** - 减少非必要支出是省钱的关键
8. **定期对账** - 每月对账确保记录准确
