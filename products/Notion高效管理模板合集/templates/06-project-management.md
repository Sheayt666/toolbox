# 模板06：项目管理看板

> 多项目并行不慌乱，进度全掌控

---

## 一、模板简介

项目管理看板是基于看板方法论和敏捷项目管理理念设计的Notion模板。它帮助你系统化地管理多个项目，清晰追踪每个项目的进度、任务和风险，让多项目并行不再手忙脚乱，所有项目尽在掌握之中。

## 二、适用人群

- 同时管理多个项目的项目经理
- 需要跟进多个项目的自由职业者
- 工作内容碎片化的职场人士
- 想要系统化管理个人项目的效率爱好者
- 创业团队和小团队负责人

## 三、模板结构设计

### 整体架构

```
项目管理看板（主页面）
├── 📊 项目总览仪表盘
├── 📁 项目库（数据库）
├── ✅ 任务池（数据库 - 所有项目的任务汇总）
├── 🚧 风险与问题（数据库）
├── 📝 项目日志（数据库）
└── 📈 里程碑管理（数据库）
```

### 数据库关系

- 项目库 → 一对多 → 任务池
- 项目库 → 一对多 → 里程碑
- 项目库 → 一对多 → 风险与问题
- 项目库 → 一对多 → 项目日志
- 任务池 → 多对一 → 里程碑

| 截止日期 | 日期 | 项目截止时间 |

| 进度 | 公式 | 自动计算：已完成任务数 / 总任务数 |
| 完成度 | 百分比 | 手动调整或自动计算 |
| 关联任务 | 关联 | 关联到任务池 |

**进度计算公式：**
```
if(length(prop("关联任务")) == 0, 0, round(toNumber(length(filter(prop("关联任务"), (p) => p.current.data["状态"] == "已完成"))) / toNumber(length(prop("关联任务"))) * 100) / 100)
```

## 六、使用说明

### 第一步：创建项目

1. 在项目库中新建项目
2. 填写项目名称、描述、类型、优先级
3. 设置开始日期和截止日期
4. 添加项目封面（可选但推荐）
5. 设定项目阶段为「规划中」

### 第二步：制定项目计划

1. 分解项目里程碑
2. 为每个里程碑设定交付物和时间
3. 拆解任务到任务池中
4. 为每个任务设定优先级、负责人、截止日期
5. 建立任务之间的依赖关系

### 第三步：执行与追踪

1. 每天早上查看今日待办任务
2. 更新任务状态（待办 → 进行中 → 已完成）
3. 记录实际工时
4. 遇到问题及时记录到风险与问题库
5. 定期更新项目日志

### 第四步：项目复盘

1. 项目完成后更新状态为「已完成」
2. 记录项目总结和经验教训
3. 统计项目实际工时和预计工时对比
4. 归档项目资料

## 七、最佳实践

1. **任务粒度适中** - 每个任务以2-8小时完成为宜，太大要拆分，太细则太碎
2. **定期站会** - 每天花10分钟回顾昨日完成、今日计划、遇到的问题
3. **可视化进度** - 用看板视图让进度一目了然
4. **及时更新状态** - 任务状态变化要及时更新，保持信息同步
5. **风险管理前置** - 提前识别风险，不要等问题发生了才应对
6. **善用关联** - 任务、里程碑、风险都关联到项目，方便查看全貌
7. **不要过度规划** - 先做最重要的，在执行中逐步完善
8. **定期复盘** - 项目结束后一定要复盘，积累经验
