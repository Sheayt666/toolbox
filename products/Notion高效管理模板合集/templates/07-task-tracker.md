# 模板07：任务追踪系统

> GTD方法论落地，告别拖延症

---

## 一、模板简介

任务追踪系统是基于GTD（Getting Things Done）方法论和艾森豪威尔矩阵设计的Notion模板。它帮助你收集、整理、执行所有的待办任务，让大脑从记忆任务中解放出来，专注于真正重要的事情，彻底告别拖延和遗忘。

## 二、适用人群

- 经常忘记事情、丢三落四的人
- 任务太多不知道从何下手的拖延症患者
- 想要系统管理待办事项的职场人士
- GTD方法论的实践者和爱好者
- 希望提升执行力的效率追求者

## 三、模板结构设计

### 整体架构

```
任务追踪系统（主页面）
├── 📥 收件箱（快速收集）
├── ✅ 今日待办（今日视图）
├── 📋 任务数据库（核心数据库）
├── 🏷️ 情境清单（按情境分类）
├── 📅 日程安排（日历视图）
┗ 📊 完成统计（数据汇总）
```

### GTD工作流

1. **收集** - 所有想法先丢进收件箱
2. **整理** - 每天整理收件箱，判断是否需要行动
3. **组织** - 给任务设定属性（优先级、情境、截止日期等）
4. **回顾** - 定期回顾任务清单
5. **执行** - 根据情境和精力选择合适的任务执行

## 五、视图设计

1. **收件箱视图** - 只显示状态=收件箱的任务，用于快速收集

4. **逾期任务视图** - 截止日期<今天 且 状态≠已完成的任务

5. **看板视图（按状态）** - 收件箱、待办、进行中、等待中、已完成
6. **看板视图（按优先级）** - 四象限：重要紧急、重要不紧急、紧急不重要、不重要不紧急
7. **列表视图（按类型）** - 按任务类型分组
8. **情境视图** - 按情境分组，便于在特定场景下选择任务

### 其他视图

9. **日历视图** - 按截止日期展示，一目了然

## 六、使用说明

### 第一步：收集（随时随地）

1. 想到任何需要做的事情，立即添加到收件箱
2. 不用分类，不用判断，快速记录下来
3. 可以用手机端快速添加
4. 目标是：清空大脑，让所有待办都在系统里

### 第二步：整理（每天早上5分钟）

1. 打开收件箱，逐条处理
2. 判断这件事需要行动吗？
   - **不需要** → 删除 / 归档到参考资料
   - **需要** → 继续判断
3. 两分钟内能做完吗？
   - **能** → 立即做，然后标记完成
   - **不能** → 继续整理
4. 需要别人做吗？
   - **是** → 标记为「等待中」，记录等待谁
   - **否** → 设定属性，放入待办清单
5. 给任务设定：优先级、情境、预计耗时、截止日期等

### 第三步：规划（每周日30分钟）

1. 回顾所有任务
2. 确定本周重点任务
3. 给本周任务安排大致时间
4. 清理过期和不再需要的任务
5. 更新「某天/也许」列表

### 第四步：执行（每天）

1. 早上查看今日待办
2. 根据当前情境和精力选择任务
3. 专注完成一个任务后再开始下一个
4. 完成后标记为「已完成」
5. 新想到的任务先丢进收件箱

### 第五步：回顾（每周）

1. 查看已完成的任务，给自己肯定
2. 检查逾期任务，更新状态或时间
3. 规划下周任务
4. 清理和优化任务清单

## 七、最佳实践

1. **两分钟原则** - 两分钟内能做完的事，立刻就做，不要放进清单
2. **一次只做一件事** - 专注比多任务并行效率高得多
3. **定期清空收件箱** - 收件箱不能堆积，每天都要处理
4. **任务要具体** - "做项目"太模糊，"完成项目方案第一版"才是好任务
5. **分解大任务** - 大任务要拆成小步骤，否则容易拖延
6. **保护重要不紧急** - 多花时间在重要不紧急的事情上，这才是成长的关键
7. **善用等待时间** - 通勤、排队时处理短任务
8. **不要追求完美** - 任务系统是工具，不是负担，适合自己就好
9. **定期断舍离** - 定期清理不再需要的任务，保持清单清爽
10. **奖励自己** - 完成重要任务后给自己一点小奖励
