## 一、基础操作技巧

### 1. 快速创建页面

- 输入 `/` 打开命令菜单，快速插入各种内容块
- 输入 `[[` 快速链接到其他页面或创建新页面
- 使用模板按钮（Template Button）一键生成标准化页面
- 在侧边栏右键点击 → 新建页面

### 2. 快速格式化文本

- **加粗**：选中文字按 `Ctrl/Cmd + B`，或输入 `**文字**`
- *斜体*：选中文字按 `Ctrl/Cmd + I`，或输入 `*文字*`
- ~~删除线~~：输入 `~~文字~~`
- `行内代码`：输入 `` `文字` ``
-  ==高亮==：输入 `==文字==`

### 3. 标题层级

- 输入 `# ` + 空格 → 一级标题
- 输入 `## ` + 空格 → 二级标题
- 输入 `### ` + 空格 → 三级标题
- 快捷键：`Ctrl/Cmd + 数字键1/2/3`

### 4. 列表操作

- 输入 `- ` 或 `* ` → 无序列表
- 输入 `1. ` → 有序列表
- 输入 `- [ ] ` → 待办事项
- `Tab` 缩进，`Shift + Tab` 取消缩进
- 拖动列表项可以重新排序

### 5. 实用块类型

- **引用块**：输入 `> ` → 引用样式
- **分割线**：输入 `---` → 水平分割线
- **代码块**：输入 ``` → 代码块，支持多种语言高亮
- **切换列表**：输入 `> ` + 标题 → 可折叠的切换列表
- **标注块（Callout）**：输入 `/callout` → 带图标的提示块
- **同步块**：输入 `/synced` → 多处同步更新的内容块

### 6. 快速跳转

- `Ctrl/Cmd + K`：添加链接或搜索页面
- `Ctrl/Cmd + P`：快速搜索和跳转到任意页面
- `Ctrl/Cmd + O`：打开最近浏览的页面
- 面包屑导航：点击页面标题上方的路径快速返回

- **多条件筛选**：可以同时设置多个筛选条件
- **筛选组**：支持 AND/OR 逻辑组合
- **按日期筛选**：今天、本周、本月、过去7天等快捷选项
- **按人员筛选**：筛选我创建的、我负责的
- **保存视图**：不同的筛选条件保存为不同视图
- **临时筛选**：不保存，仅当前查看使用

### 4. 排序与分组

- **多级排序**：先按A排序，再按B排序
- **升序/降序**：数字、日期、文本都支持
- **手动排序**：拖拽调整顺序
- **分组功能**：按单选、多选、人员等属性分组
- **折叠分组**：可以折叠/展开分组

### 5. 数据库模板

- 新建数据库时可以选择模板

- 可以创建自己的数据库模板
- 模板按钮可以一键生成数据库条目

### 6. 关联数据库高级玩法

- **双向关联**：A关联B，B自动关联A
- **自关联**：数据库自己关联自己（如组织架构）
- **多级关联**：通过中间表实现多对多关系
- **汇总函数**：对关联数据进行求和、计数、平均值
- **反向查找**：从关联表中查找特定数据

### 2. 实用公式示例

#### 计算进度百分比

```
round(prop("已完成") / prop("总数") * 100) / 100
```

#### 根据状态显示emoji

```
if(prop("状态") == "已完成", "✅",
if(prop("状态") == "进行中", "🚀",
if(prop("状态") == "待办", "📋", "❌")))
```

#### 计算剩余天数

```
dateBetween(prop("截止日期"), now(), "days")
```

#### 判断是否逾期

```
if(and(prop("状态") != "已完成", dateBetween(prop("截止日期"), now(), "days") < 0), "🔴 逾期",
if(dateBetween(prop("截止日期"), now(), "days") <= 3, "🟡 即将到期", "🟢 正常"))
```

#### 计算年龄

```
floor(dateBetween(now(), prop("出生日期"), "years"))
```

#### 计算星期几

```
formatDate(prop("日期"), "dddd")
```

#### 提取月份

```
formatDate(prop("日期"), "YYYY-MM")
```

#### 复选框计数（统计完成数）

```
toNumber(prop("任务1")) + toNumber(prop("任务2")) + toNumber(prop("任务3"))
```

### 3. 公式编写技巧

1. **从简单开始**：先写简单的逻辑，再逐步叠加
2. **分步测试**：复杂公式可以拆成几个中间字段验证
3. **注意数据类型**：数字和文本不能直接运算，要用format转换
4. **善用嵌套if**：多个条件判断用if嵌套
5. **空值处理**：用empty()判断字段是否为空，避免报错
6. **日期运算**：注意单位是"days"、"months"、"years"等
7. **格式美化**：用concat拼接emoji和文本，让结果更直观

## 五、页面美化技巧

### 1. 页面图标和封面

- **页面图标**：点击页面标题左边的图标，可以选择emoji、上传图片或搜索图标
- **页面封面**：点击添加封面，可以选择纯色、渐变、图片或上传自己的图片
- **推荐封面网站**：
  - Unsplash：高质量免费图片
  - Pexels：免费素材
  - 渐变生成器：各种渐变效果

### 2. 字体和排版

- Notion支持三种字体：默认、衬线（Serif）、等宽（Mono）
- 可以在页面设置中切换字体
- 合理使用标题层级：H1大标题、H2中标题、H3小标题
- 使用分割线分隔不同内容区块
- 适当留白，不要堆得太满

### 3. 颜色使用

- 文字可以设置颜色：默认、灰色、棕色、橙色、黄色、绿色、蓝色、紫色、粉色、红色
- 背景也可以设置颜色
- 配色建议：
  - 同一页面颜色不超过3种
  - 重要内容用醒目的颜色
  - 同一类型内容用相同颜色
  - 注意颜色和背景的对比度

### 4. 分栏布局

- 拖动块可以创建多栏布局
- 可以做2栏、3栏、甚至4栏
- 每栏宽度可以拖动调整
- 适合做仪表盘、对比展示等

### 5. 标注块（Callout）美化

- 输入 `/callout` 创建标注块
- 可以更换图标（emoji）
- 可以设置背景颜色
- 适合做提示、警告、重点说明等
- 常用搭配：
  - 💡 黄色背景：小提示
  - ⚠️ 橙色背景：注意事项
  - ❌ 红色背景：错误警告
  - ✅ 绿色背景：成功/正确
  - 📌 蓝色背景：重要信息

### 6. 切换块（Toggle）使用

- 输入 `/toggle` 创建切换块
- 可以折叠/展开内容
- 适合存放详细内容、FAQ、附录等
- 可以嵌套使用，做多级折叠
- 让页面更简洁，按需展开

### 7. 表格美化

- 简单表格（不是数据库）可以设置表头
- 可以合并单元格
- 可以设置列宽
- 适合做简单的对比和展示

### 8. 视觉元素推荐

- **图标/Emoji**：每个模块标题前加一个图标
- **分割线**：用 `---` 分隔不同内容区
- **引用块**：重要内容用引用突出
- **标注块**：提示信息用标注块
- **画廊视图**：图片内容用画廊展示
- **进度条**：用公式或文本模拟进度条

### 9. 美化小技巧

1. **统一风格**：同一工作区保持一致的风格
2. **少即是多**：不要堆太多元素，简洁最美
3. **对齐很重要**：内容尽量对齐，看起来更整洁
4. **善用空白**：适当留白，呼吸感很重要
5. **图标有含义**：选择的图标要和内容相关
6. **配色和谐**：同一页面颜色不要太杂
7. **层级分明**：标题、正文、辅助内容区分清楚
8. **定期整理**：定期清理和优化页面布局

## 六、效率提升技巧

### 1. 模板按钮（Template Button）

- 输入 `/template button` 创建模板按钮
- 可以预设任何内容：页面、列表、数据库条目等
- 点击按钮一键生成预设内容
- 适合：日记、周报、会议纪要、任务等标准化内容
- 可以设置按钮名称和图标

### 2. 数据库模板

- 数据库可以创建多个条目模板
- 新建条目时选择对应模板
- 适合：不同类型的任务、不同分类的笔记等
- 可以设置默认属性值
- 可以预设页面内容结构

### 3. 快速录入技巧

- **移动端**：Widgets小组件、快捷指令、分享扩展
- **网页剪藏**：Notion Web Clipper浏览器插件
- **邮件转Notion**：发送邮件到指定地址创建页面
- **第三方工具**：Zapier、Make等自动化工具

### 4. 搜索技巧

- `Ctrl/Cmd + P` 快速搜索页面
- 支持模糊搜索，不用输入完整名称
- 可以搜索页面标题和内容
- 搜索结果可以按最近访问排序
- 数据库内搜索：`Ctrl/Cmd + F` 只搜索当前视图

### 5. 链接反向链接

- 页面之间互相链接，形成知识网络
- 页面底部可以看到反向链接（哪些页面链接了本页）
- 反向链接可以展开查看上下文
- 适合构建知识库、笔记系统
- `[[` 快速创建双向链接

### 6. 侧边栏整理

- 常用页面加到收藏夹（侧边栏顶部）
- 不用的页面可以归档
- 合理使用文件夹组织页面
- 可以给页面排序
- 侧边栏可以折叠和展开

### 7. 批量操作

- 选中多个块可以批量操作
- 数据库中可以批量选中多行修改属性
- 可以批量移动、删除、转换块类型
- `Esc` 取消选中

### 8. 工作流优化

1. **收件箱方法**：所有内容先丢进收件箱，定期整理
2. **每周整理**：每周花时间整理Notion内容
3. **模板化**：重复的内容做成模板
4. **自动化**：能用工具自动完成的就手动
5. **少即是多**：页面和数据库不要太多，够用就好
6. **定期清理**：删除不需要的内容，保持清爽

## 七、高级功能玩法

### 1. 按钮（Button）属性

- 数据库的按钮属性，可以配置点击后执行的操作
- 支持的操作：
  - 打开页面
  - 编辑属性（修改当前行的字段值）
  - 添加到数据库（在另一个数据库新建条目）
  - 显示确认弹窗
  - 打开链接
- 可以串联多个操作（步骤）
- 适合：一键完成、标记完成、快速添加等

### 2. 数据库内页面（New page template）

- 数据库的每个条目都是一个页面
- 可以自定义新建页面的模板
- 模板中可以使用属性变量：`{属性名}`
- 适合标准化内容结构
- 可以创建多个模板，新建时选择

### 3. 关联数据库（Linked database）

- 在任意页面嵌入其他数据库的视图
- 同一个数据库可以在多处展示不同视图
- 修改数据是实时同步的
- 适合：仪表盘、汇总页面、专题页面
- 可以设置不同的筛选、排序、分组

### 4. 高级过滤

- 支持多条件组合筛选
- AND/OR 逻辑嵌套
- 可以按当前用户筛选（"我"）
- 可以按相对日期筛选（今天、本周、本月等）
- 可以保存为不同视图

### 5. 公式高级用法

- 复杂的条件判断
- 日期计算和格式化
- 文本处理和拼接
- 数学运算
- 可以用公式生成动态的emoji和状态显示

### 6. API 和 集成

- Notion有官方API，可以开发自己的工具
- 支持Zapier、Make等自动化平台
- 可以和其他工具联动：Slack、Gmail、Google日历等
- 可以自动备份、导入导出数据
- 适合有编程基础的用户

### 7. 同步块（Synced block）

- 内容在多处同步显示和更新
- 修改一处，所有地方同步更新
- 适合：通用内容、页眉页脚、重要通知
- 可以跨页面同步
- 输入 `/synced` 创建

### 8. 评论和讨论

- 可以在页面和数据库中添加评论
- 支持@提及人
- 支持回复评论，形成讨论串
- 可以解决评论（标记为已解决）
- 适合团队协作和反馈

## 十、常见问题解答

### 1. 数据安全吗？

- Notion使用加密存储
- 有版本历史，可以恢复误删内容
- 建议定期导出备份重要数据
- 敏感信息可以考虑加密后再存

### 2. 数据可以导出吗？

- 可以导出为Markdown、HTML、PDF、CSV格式
- 可以导出单个页面或整个工作区
- 导出的文件可以导入其他工具
- 建议定期备份重要数据

### 3. Notion很慢怎么办？

- 页面内容太多会变慢，适当拆分
- 数据库条目太多可以用筛选减少显示
- 关闭不必要的预览和嵌入
- 清理不用的大文件和图片
- 使用桌面端比网页版流畅

### 4. 如何快速上手？

- 从一个简单的使用场景开始（比如待办清单）
- 不要一开始就建太多页面和数据库
- 慢慢摸索，边用边学
- 看官方教程和社区分享
- 先模仿再创新

### 5. 免费版够用吗？

- 个人使用免费版基本够用
- 免费版有上传文件大小限制（5MB/个）
- 免费版可以创建无限个页面和块
- 团队协作建议用付费版

### 6. 数据可以迁移吗？

- 支持从Evernote、Trello、Asana等工具导入
- 可以导出为Markdown迁移到其他工具
- 数据库可以导出为CSV
- 建议重要数据定期备份

### 7. 如何备份？

- 手动导出：设置 → 导出所有工作区数据
- 自动备份：可以用第三方工具或API
- 建议每月备份一次重要数据
- 导出文件建议存到云端硬盘

### 8. Notion和其他笔记软件比怎么样？

- **优势**：功能强大、灵活度高、数据库强、颜值高、协作方便
- **劣势**：加载速度一般、学习曲线稍陡、国内访问有时不稳定
- **适合**：喜欢折腾、需要复杂功能、注重颜值和体验的用户
- **不适合**：追求极致速度、只需要简单记笔记的用户
