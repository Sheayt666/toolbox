#### E-01 会议纪要生成器

**适用场景**：快速整理会议录音/文字记录、生成结构化会议纪要

**提示词内容**：
```
你是一位专业的会议纪要整理专家，擅长从混乱的会议记录中提炼出清晰、结构化的纪要。

以下是会议记录：
【会议主题】：[会议主题]
【会议时间】：[时间]
【参会人员】：[参会人列表及角色]
【会议形式】：[线下/线上/电话会]
【会议记录】：
[粘贴会议录音转写文字或会议笔记]

请生成专业的会议纪要：

1. 【会议基本信息】
   - 会议主题
   - 时间、地点
   - 参会人员
   - 会议主持人
   - 记录人

2. 【会议议题】
   - 本次会议的核心议题
   - 议题优先级

3. 【讨论内容摘要】
   
   议题一：[议题名称]
   - 讨论背景
   - 主要观点（正反两方面）
   - 关键争论点
   - 共识点
   
   议题二：[议题名称]
   - ...

4. 【会议决议/结论】
   - 决议1：具体内容
   - 决议2：具体内容
   - ...
   - 每项决议标注表决方式（一致通过/多数通过/待定）

5. 【行动项（Action Items）】
   
   | 序号 | 任务内容 | 负责人 | 截止日期 | 优先级 | 状态 |
   |------|----------|--------|----------|--------|------|
   | 1 | | | | 高/中/低 | 待办 |
   | 2 | | | | | |

6. 【待跟进事项】
   - 需要进一步讨论的问题
   - 需要收集的信息
   - 下次会议的议题建议

7. 【风险与问题】
   - 讨论中发现的风险
   - 潜在的问题
   - 需要关注的事项

纪要要求：
- 客观准确，不加入主观判断
- 重点突出，详略得当
- 行动项明确，有责任人有时间
- 语言简洁专业
- 便于会后执行和跟进

如果会议记录不完整或有模糊的地方，请标注"【待确认】"。
```

#### E-05 番茄工作法助手

**适用场景**：专注工作、番茄钟计时、任务执行管理

**提示词内容**：
```

【可能的干扰】：[可能会分散注意力的事情]
【当前状态】：[精力充沛/一般/有点累]

请陪我完成番茄工作：

   - 这个任务可以分成几个番茄钟？
   - 每个番茄钟的具体目标是什么？
   
   番茄钟1：[具体目标]
   番茄钟2：[具体目标]
   番茄钟3：[具体目标]
   ...

2. 【第一个番茄钟准备】
   - 开始前需要准备什么？
   - 需要排除哪些干扰？
   - 手机/通知怎么处理？
   - 环境准备建议

   - 这个番茄钟的具体目标
   - 成功标准
   - 如果走神了怎么办？
   - 保持专注的小技巧

4. 【休息指导】
   - 5分钟短休息建议（做什么/不做什么）
   - 15-30分钟长休息建议
   - 为什么休息很重要？
   - 休息时避免的坑

5. 【每个番茄钟后的复盘】
   - 这个番茄钟完成了什么？
   - 效率如何？1-10分
   - 有什么干扰？
   - 下一个番茄钟如何改进？

6. 【遇到困难时】
   - 如果卡住了怎么办？
   - 如果任务比预想的难怎么办？
   - 如果不想继续怎么办？
   - 如何重新进入状态？

7. 【全部完成后的总结】
   - 总共用了几个番茄钟？
   - 完成了多少？
   - 效率最高的是哪个？
   - 有什么经验教训？
   - 下次如何改进？

- 25分钟专注 + 5分钟休息 = 1个番茄钟
- 每4个番茄钟后休息15-30分钟
- 一个番茄钟不可分割，中途打断就要重来
- 保护你的番茄钟，学会说"不"
- 番茄钟是工具，不是目的，灵活使用

现在，准备好开始第一个番茄钟了吗？
```

【为什么想养成/改掉】：[动机和原因]
【当前状态】：[现在的情况，为什么做不到]
【目标时间】：[希望多久养成]
【每天可投入时间】：[每天花多少时间在这个习惯上]
【之前尝试过吗】：[之前的尝试和失败原因]
【我的生活作息】：[简单描述一天的作息]
【我的性格特点】：[有助于/有碍于习惯养成的性格]

请设计科学的习惯养成方案：

1. 【习惯分析】
   - 这个习惯为什么重要？
   - 能带来什么好处？（短期/长期）
   - 做不到的核心原因是什么？
   - 最大的障碍是什么？

2. 【微习惯设计】
   
   最小可行习惯（小到不可能失败）：
   - 具体内容：
   - 为什么是这个？
   - 完成时间：X分钟
   - 完成标准：
   
   逐步升级路径：
   - 第1周：每天做X
   - 第2周：增加到X
   - 第3周：增加到X
   - ...
   - 最终目标：

3. 【触发机制】
   
   习惯触发器：
   - 时间触发：每天X点
   - 地点触发：在X地方
   - 事件触发：做完X之后
   - 情绪触发：当X的时候
   
   环境设计：
   - 如何让好习惯更容易？
   - 如何让坏习惯更难？
   - 物理环境改造建议
   - 社交环境利用

4. 【奖励机制】
   
   内在奖励：
   - 如何感受习惯本身的快乐？
   - 如何建立内在动机？
   
   外在奖励：
   - 每日奖励：
   - 每周奖励：
   - 里程碑奖励：
   
   惩罚机制（可选）：
   - 没做到怎么办？
   -  accountability伙伴

5. 【习惯追踪】
   
   追踪方式：
   - 打卡方式建议
   - 记录什么数据？
   - 如何复盘？
   
   视觉化：
   - 习惯链（不要断掉链条）
   - 日历打卡
   - 进度条
   
   每周复盘：
   - 完成情况
   - 成功的原因
   - 失败的原因
   - 下周调整

6. 【应对策略】
   
   当不想做的时候：
   - 怎么办？
   - 如何启动？
   - "2分钟法则"应用
   
   当打断/中断的时候：
   - 如何恢复？
   - 如何避免"全有或全无"思维？
   - "错过一次，不要错过第二次"
   
   当遇到瓶颈的时候：
   - 如何突破？
   - 如何保持新鲜感？
   - 如何调整难度？

7. 【习惯叠加】
   - 这个习惯可以和哪些已有习惯绑定？
   - 习惯链设计
   - 一天中的最佳时间
   - 与其他习惯的协同效应

8. 【身份认同】

   - 身份认同建设
   - 自我对话调整
   - 榜样的力量

9. 【30天行动计划】

   |------|------|------|------|
   | 第1天 | | ★☆☆☆☆ | |
   | 第2天 | | | |
   | ... | | | |
   | 第30天 | | ★★★★☆ | |

10. 【常见误区与避坑】
    - 一开始用力过猛
    - 追求完美
    - 同时培养太多习惯
    - 只靠意志力
    - 忽视环境的力量

习惯养成原则：
- 从小处开始，小到不可能失败
- 环境设计 > 意志力
- 建立奖励，让大脑喜欢上它
- 追踪和可视化
- 允许失败，但不要连续失败两次
- 坚持比完美更重要
