## 第一部分：提示词使用基础

### 1.1 什么是好的提示词？

一个高质量的提示词通常具备以下特征：

| 特征 | 说明 | 示例 |
|------|------|------|
| **角色清晰** | 明确 AI 要扮演的身份 | "你是一位资深产品经理" |
| **任务具体** | 描述清楚要做什么 | "撰写一份产品需求文档"而非"帮我写点东西" |
| **背景完整** | 提供必要的上下文信息 | 目标用户、使用场景、约束条件 |
| **输出明确** | 指定输出格式和长度 | "用表格形式呈现，不超过 500 字" |
| **约束清晰** | 说明不能做什么 | "不要使用专业术语，面向普通读者" |

### 1.2 提示词的基本结构

建议使用 **"角色 + 背景 + 任务 + 输出要求"** 四步法构建提示词：

```
【角色设定】你是一位[专业身份]，拥有[X年经验/专业背景]。

【背景信息】
- 项目/主题：[具体内容]
- 目标受众：[谁会看这个输出]
- 使用场景：[在什么情况下使用]
- 约束条件：[有什么限制或要求]

【任务要求】
请帮我完成[具体任务]，需要注意：
1. [要求一]
2. [要求二]
3. [要求三]

【输出格式】
- 格式：[Markdown/表格/列表/JSON等]
- 长度：[大约多少字/几页]
- 风格：[正式/轻松/专业/幽默等]
```

### 1.3 如何使用本提示词包中的提示词

**第一步：选择合适的提示词**
- 根据你的工作场景，在对应分类中查找
- 阅读"适用场景"判断是否匹配你的需求
- 优先选择编号靠前的经典提示词

**第二步：定制化修改**
- 替换提示词中的 `[占位符]` 为你的实际内容
- 根据具体需求增删条件
- 调整输出格式和长度要求

**第三步：执行与迭代**
- 将修改后的提示词发送给 AI
- 检查输出结果是否符合预期
- 如不满意，使用本指南中的优化方法进行迭代

## 第二部分：高效使用提示词的 7 个技巧

### 技巧一：给 AI 一个"身份"

**原理**：当你给 AI 设定一个具体的专业角色时，它的回答会更有针对性和专业性。

**对比示例**：

❌ 普通提问：
```
帮我写一封道歉邮件
```

✅ 角色设定：
```
你是一位有着10年客户服务经验的客服总监，擅长处理客户投诉和维护客户关系。

请帮我写一封道歉邮件给一位因产品质量问题而非常不满的客户。
要求：
- 语气真诚但不失专业
- 既表达歉意又给出解决方案
- 尽量挽回客户信任
- 字数控制在 300 字以内
```

**常用角色模板**：
- 写作类：资深编辑、品牌文案、专栏作家、新媒体运营
- 编程类：架构师、代码审查专家、性能优化工程师、技术文档作家
- 设计类：UI/UX 设计师、品牌设计师、用户体验研究员
- 营销类：营销总监、增长黑客、品牌策划、内容运营
- 商业类：战略顾问、投资分析师、产品总监、市场研究员

### 技巧二：提供充分的上下文

**原理**：AI 不知道你知道的信息，你提供的上下文越充分，输出越精准。

**上下文清单**（根据需要选择）：
- 目标受众是谁？（年龄、职业、知识水平）
- 用于什么场景？（工作汇报/社交媒体/学术论文）
- 有什么背景信息？（项目历史、之前的沟通、已知数据）
- 有什么限制条件？（字数、格式、风格、合规要求）
- 期望达到什么效果？（说服/告知/娱乐/销售）

**示例**：

❌ 信息不足：
```
帮我写一篇关于AI的文章
```

✅ 信息充分：
```
请帮我写一篇面向中小企业主的 AI 应用入门文章。

背景信息：
- 目标读者：35-50岁的传统行业中小企业主
- 读者痛点：听说 AI 很火但不知道怎么用在自己的生意上
- 文章目的：降低认知门槛，激发他们尝试 AI 的兴趣
- 发布渠道：公众号推文
- 字数要求：1500-2000字
- 风格要求：通俗易懂，多用案例，避免技术术语

请包含以下内容：
1. 什么是 AI（用生活化的比喻解释）
2. AI 在中小企业中的 5 个典型应用场景（每个配真实感的案例）
3. 零基础开始用 AI 的 3 个简单步骤
4. 常见误区和注意事项
```

### 技巧三：指定输出格式

**原理**：明确的格式要求能让 AI 的输出更有条理，也方便你后续使用。

**常用格式指令**：

| 格式 | 指令示例 |
|------|----------|
| 列表 | "用要点列表的形式呈现" |
| 表格 | "用 Markdown 表格整理，列包括：名称、特点、适用场景" |
| 分步 | "按步骤说明，第一步、第二步..." |
| 模板 | "提供一个可直接填空的模板" |
| JSON | "输出为 JSON 格式，字段包括..." |
| 对比 | "用对比表格的形式呈现 A 和 B 的区别" |
| 金字塔 | "先总结核心观点，再分层展开论据" |

**进阶格式技巧**：
- 要求输出包含"标题 + 摘要 + 正文"的结构
- 指定标题层级（H1、H2、H3）
- 要求关键信息加粗或高亮
- 指定段落长度（每段不超过 3 句话）

### 技巧四：善用"示例"引导

**原理**：给出一个你期望的输出示例，AI 能更快理解你的需求和风格。

**使用方法**：

```
请按照以下示例的风格和格式，为我生成 [新内容]。

【示例】
这里放你满意的样例内容...

【新内容要求】
这里放新的具体需求...
```

**适用场景**：
- 保持风格一致性（如系列文章、品牌文案）
- 学习特定写作格式（如小红书风格、知乎风格）
- 复制某种结构但替换内容
- 模仿特定的语气和调性

**注意事项**：
- 示例质量直接影响输出质量
- 示例越具体，输出越符合预期
- 可以用"反例"说明你不想要什么

### 技巧五：分步复杂任务

**原理**：对于复杂任务，拆分成多个步骤比一次性要求更有效。

**示例——写一篇深度文章**：

❌ 一步到位：
```
帮我写一篇关于远程办公的深度文章，5000字
```

✅ 分步执行：
```
第一步：请为"远程办公的未来趋势"这个主题拟定 5 个文章大纲，每个大纲包含 3-5 个核心章节。

（等待 AI 输出后，选择一个满意的大纲）

第二步：基于大纲第 X 个版本，请为每个章节撰写详细的小节标题和核心观点。

（等待 AI 输出后）

第三步：请基于以上大纲，撰写第一章的完整内容，约 1000 字。
...
```

**分步策略的好处**：
- 每一步都可以纠偏，避免走偏太远
- 输出质量更高，因为 AI 能更聚焦
- 你有更多控制权，可以随时调整方向
- 适合长文、复杂分析、创意项目等

### 技巧六：让 AI 自我审查

**原理**：让 AI 检查自己的输出，能显著提升质量。

**常用审查指令**：

```
在给出最终答案前，请先：
1. 检查你的回答是否准确、完整
2. 找出可能存在的逻辑漏洞或事实错误
3. 评估回答是否满足了所有要求
4. 如有不足，请修正后再输出
```

**专项审查指令**：

| 审查类型 | 指令 |
|----------|------|
| 事实核查 | "请核查你提到的数据和事实是否准确，如有不确定的请注明" |
| 逻辑审查 | "请检查你的论证逻辑是否严密，找出可能的推理漏洞" |
| 风格检查 | "请检查文案是否符合品牌调性，标注出不符合的地方" |
| 代码审查 | "请审查你生成的代码，检查是否有 bug、性能问题或安全隐患" |
| 完整性检查 | "对照原始需求逐条检查，确认是否所有要求都已满足" |

**高级技巧——双重生成法**：
```
请从两个不同的角度分别生成两个版本的答案，然后对比分析各自的优缺点，最后给出一个综合优化版本。
```

### 技巧七：建立反馈循环

**原理**：通过迭代优化，逐步让输出达到理想状态。

**反馈模板**：

```
整体不错，但我有几点修改意见：

1. 【内容调整】关于[某部分]，希望改成[具体修改方向]
2. 【风格调整】语气可以更[正式/轻松/专业]一些
3. 【结构调整】把[某部分]移到[某个位置]会更好
4. 【补充内容】请增加关于[某个主题]的内容
5. 【删减内容】[某部分]可以简化或删除

请基于以上意见修改后重新输出。
```

**迭代次数建议**：
- 简单任务：1-2 次迭代
- 中等任务：2-3 次迭代
- 复杂/重要任务：3-5 次迭代
- 创意类任务：建议多轮迭代，逐步逼近理想效果

## 第三部分：提示词修改与优化方法论

### 3.1 提示词优化的 CRISP 框架

**CRISP** 是提示词优化的五个核心维度：

| 维度 | 英文 | 说明 | 检查清单 |
|------|------|------|----------|
| **C** | Clear（清晰） | 指令是否明确无歧义 | 是否有多种解读方式？术语是否统一？ |
| **R** | Relevant（相关） | 信息是否与任务相关 | 是否有多余的干扰信息？是否遗漏关键信息？ |
| **I** | Specific（具体） | 要求是否具体可执行 | "好一点"→ 具体怎么好？"专业点"→ 哪个领域的专业？ |
| **S** | Structured（结构化） | 是否有清晰的组织 | 用编号、分点、分段组织了吗？ |
| **P** | Purposeful（有目标） | 是否明确预期效果 | AI 知道"好"的标准是什么吗？ |

### 3.2 常见问题诊断与优化

#### 问题一：输出太泛泛，没有深度

**诊断**：提示词太笼统，缺乏具体约束。

**优化方法**：
- 增加受众画像
- 明确使用场景
- 限定讨论范围
- 要求具体案例
- 指定深度/角度

**示例**：

❌ 原版：
```
帮我分析一下电商行业
```

✅ 优化版：
```
请从以下三个维度分析 2024 年中国直播电商行业的发展状况：

1. 市场格局：主要玩家有哪些？各自的市场份额和特点是什么？
2. 核心趋势：今年出现了哪些重要趋势？（至少 3 个）
3. 未来机会：对于中小商家来说，还有哪些切入机会？

要求：
- 每个维度的分析不少于 300 字
- 结合具体的数据和案例
- 面向有一定行业经验的从业者
- 避免泛泛而谈，要有洞察深度
```

#### 问题二：输出太长/太短

**诊断**：没有明确的长度要求，或要求太模糊。

**优化方法**：
- 明确字数范围（如"800-1000字"）
- 指定结构和各部分长度
- 用"要点数量"控制
- 要求"精简版"或"详细版"

**长度控制技巧**：
```
- 一句话版本：用不超过 50 字概括
- 电梯演讲版：30 秒内能讲完的版本（约 100 字）
- 标准版：完整阐述（约 500 字）
- 深度版：详细分析（2000 字以上）
```

#### 问题三：风格不对味

**诊断**：没有指定风格，或风格描述太模糊。

**优化方法**：
- 用具体风格名称（"小红书风格"、"官媒风格"）
- 给出风格参照物（"类似某某博主的风格"）
- 描述语气特征（"亲切但专业"、"幽默又有干货"）
- 提供正面和负面示例

**风格调色板**：

| 风格维度 | 选项 |
|----------|------|
| 正式程度 | 非常正式 / 正式 / 中性 / 轻松 / 非常随意 |
| 情感浓度 | 理性客观 / 略带情感 / 情感丰富 / 激情澎湃 |
| 专业程度 | 大白话 / 入门级 / 进阶级 / 专家级 |
| 叙述角度 | 第一人称 / 第二人称 / 第三人称 / 上帝视角 |
| 节奏快慢 | 紧凑精炼 / 适中 / 娓娓道来 / 详细展开 |

#### 问题四：AI 总是"打太极"，给不出明确观点

**诊断**：提示词没有要求明确立场，或 AI 出于谨慎倾向于中立。

**优化方法**：
- 明确要求"给出明确观点"
- 要求"站队"并说明理由
- 指定讨论的立场或角度
- 限制"一方面...另一方面..."的使用

**示例指令**：
```
请不要模棱两可，给出你的明确判断，并说明理由。如果有不确定性，请标注置信度。
```

```
请站在[创业者/投资人/用户]的角度，给出倾向性意见，而不是各打五十大板。
```

#### 问题五：输出有事实错误或幻觉

**诊断**：AI 可能会编造信息，尤其是涉及具体数据和事实时。

**应对方法**：
- 要求 AI 标注信息来源或置信度
- 要求"如有不确定的请注明"
- 对关键事实进行二次验证
- 提供你已知的正确信息作为参考

**防范指令**：
```
重要提示：
- 如果你不确定某个信息，请明确说"我不确定"，不要编造
- 涉及具体数据时，请注明数据来源或说明"这是估算值"
- 对于有争议的观点，请说明不同的立场
```

### 3.3 提示词迭代优化流程

```
第 1 轮：基础版本
  ↓
  ├─ 检查：输出是否基本符合预期？
  │
  ├─ 是 → 进入第 2 轮，优化细节
  │
  └─ 否 → 诊断问题，调整提示词核心结构
          ↓
        重新生成

第 2 轮：细节优化
  ↓
  ├─ 调整语气、风格、长度
  ├─ 补充或删减内容
  ├─ 调整结构和顺序
  ↓

第 3 轮：精修打磨
  ↓
  ├─ 润色语言
  ├─ 检查逻辑和事实
  ├─ 最终确认
  ↓
完成
```

## 第四部分：常见问题与解决方案

### Q1：为什么同一个提示词，每次输出质量差异很大？

**A**：这是正常现象。大语言模型有一定的随机性。建议：
- 如果第一次输出不满意，重新生成一次试试（同一提示词多生成几次，选最好的）
- 把好的输出保存下来，作为示例引导后续生成
- 重要任务多生成几个版本，择优使用

### Q2：AI 总是忽略我的某些要求怎么办？

**A**：尝试以下方法：
1. 把最重要的要求放在开头和结尾（首尾效应）
2. 用加粗、编号等方式突出关键要求
3. 要求 AI 在回答前先复述你的要求，确认理解正确
4. 把复杂要求拆分成多个简单指令

### Q3：如何让 AI 的输出更有"人味"？

**A**：增加以下元素：
- 设定具体的人设（年龄、性格、背景故事）
- 要求使用口语化表达，避免书面语
- 加入情感和主观感受
- 允许适度的不完美和个性
- 参考某个具体的人物风格

### Q4：提示词太长会不会影响效果？

**A**：适度的长度是好的，但要注意：
- 关键信息不要被淹没在无关信息中
- 结构要清晰，用标题、编号分隔
- 太长的提示词可以分段发送
- 核心要求放在最前面

**经验值**：
- 简单任务：50-200 字
- 中等任务：200-500 字
- 复杂任务：500-1000 字
- 超复杂任务：建议分步骤进行

### Q5：不同 AI 模型（GPT、Claude、文心一言等）的提示词通用吗？

**A**：基本通用，但有细微差别：
- 核心逻辑（角色、任务、格式、约束）适用于所有主流模型
- 某些模型对特定指令的响应更好（如 Claude 擅长长文本，GPT 擅长代码）
- 建议在不同模型上测试调整
- 本提示词包中的内容经过优化，在主流模型上都有不错的效果

### Q6：如何处理 AI 的"废话文学"？

**A**：在提示词中加入：
```
要求：
- 直接给出核心内容，不要铺垫和客套
- 每句话都要有信息量
- 不要重复说同样的意思
- 能用一句话说清的不要用三句话
```

## 第五部分：进阶玩法——打造个人提示词库

### 5.1 为什么要建立个人提示词库？

- 积累常用的高效提示词，避免重复造轮子
- 形成个人的工作方法论和模板体系
- 随用随取，大幅提升工作效率
- 持续优化迭代，越用越好用

### 5.2 提示词库的组织方式

**按使用频率**：
- 高频（每天用）：放在最容易访问的位置
- 中频（每周用）：分类整理
- 低频（偶尔用）：归档保存

**按使用场景**：
- 工作类（会议、汇报、邮件、文档）
- 学习类（笔记、总结、翻译、答疑）
- 生活类（旅行、美食、健康、购物）
- 创作类（写作、编程、设计、创意）

**按成熟度**：
- 测试版：新写的提示词，还在验证效果
- 稳定版：经过多次使用，效果可靠
- 精品版：反复打磨优化，效果极佳
