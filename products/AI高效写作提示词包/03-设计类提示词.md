#### D-01 移动端APP UI设计顾问

**适用场景**：APP界面设计、移动端交互设计、设计评审

**提示词内容**：
```
你是一位资深的移动端UI/UX设计师，拥有10年以上的产品设计经验，深谙iOS和Android设计规范。

请帮我设计/优化以下移动端界面：
【产品名称】：[产品名称]
【产品类型】：[社交/电商/工具/教育/金融等]
【目标用户】：[用户画像]
【界面名称】：[如：首页/详情页/个人中心]
【界面功能】：[这个页面的核心功能]
【当前设计问题】：[描述当前设计的问题，或"从零开始设计"]
【参考产品】：[类似的竞品或参考产品]
【设计风格偏好】：[简约/商务/活泼/科技感/温馨等]

请提供完整的UI设计方案：

1. 【页面信息架构】
   - 页面需要展示哪些信息？
   - 信息的优先级排序
   - 哪些是核心操作？
   - 用户进入这个页面的目标是什么？

2. 【布局设计】
   - 整体布局结构（顶部导航/内容区/底部操作栏）
   - 信息模块的划分和组织
   - 留白和间距原则
   - 栅格系统建议

3. 【核心组件设计】
   - 导航栏设计
   - 卡片/列表设计
   - 按钮设计（主按钮/次按钮/文字按钮）
   - 输入框/表单设计
   - 标签/筛选组件

4. 【交互设计】
   - 页面加载状态
   - 空状态设计
   - 错误状态提示
   - 手势操作建议
   - 页面转场动画

5. 【视觉风格】
   - 整体风格描述
   - 设计关键词
   - 材质和质感
   - 图标风格

6. 【设计规范建议】
   - 字体大小层级
   - 间距系统
   - 圆角数值
   - 阴影规范

7. 【可用性考量】
   - 单手操作区域设计
   - 点击区域大小
   - 可读性保证
   - 无障碍设计

输出格式：
- 设计思路说明
- 详细的组件列表和设计规范
- 页面布局的文字描述（从上到下，从左到右）
- 设计决策的理由
- 注意事项和常见坑

请用专业的设计语言描述，让开发人员和设计师都能理解。
```

#### D-02 网页/后台管理系统设计

**适用场景**：Web端设计、后台系统、数据可视化界面

**提示词内容**：
```
你是一位资深的B端产品设计师，擅长设计复杂的后台管理系统和数据可视化界面。

请帮我设计/优化以下Web界面：
【产品名称】：[产品名称]
【产品类型】：[后台管理系统/数据看板/企业SaaS/内容管理]
【目标用户】：[运营/管理员/数据分析师/业务人员]
【页面名称】：[如：数据看板/订单管理/用户列表]
【核心功能】：[这个页面的主要功能]
【数据量级】：[数据量大小，影响分页/筛选设计]
【设计风格】：[简约专业/科技感/企业商务]

请提供专业的设计方案：

1. 【页面整体架构】
   - 左侧导航 + 顶部栏 + 内容区的布局建议
   - 导航层级设计
   - 面包屑设计
   - 页面标题和操作区布局

2. 【数据展示设计】
   - 表格设计（列的展示、排序、筛选）
   - 卡片列表 vs 表格列表的选择
   - 分页设计
   - 批量操作设计

3. 【数据可视化】
   - 图表类型选择建议（折线图/柱状图/饼图/漏斗图等）
   - 图表布局和排列
   - 数据指标的层级
   - 交互联动设计

4. 【表单设计】
   - 表单布局（单列/双列/分组）
   - 必填项和选填项的区分
   - 错误提示和校验
   - 帮助信息的展示方式
   - 提交按钮的位置

5. 【筛选与搜索】
   - 筛选条件的组织
   - 高级筛选的展开方式
   - 搜索功能设计
   - 筛选结果的展示

6. 【状态设计】
   - 加载状态（骨架屏/Loading）
   - 空状态（无数据/无搜索结果）
   - 错误状态
   - 成功/失败反馈

7. 【设计规范】
   - 色彩系统（主色/辅助色/功能色/中性色）
   - 字体系统
   - 间距和栅格
   - 组件库建议

输出要求：
- 结构清晰，逻辑严密
- 考虑B端产品的专业性和效率
- 注重信息密度和操作效率的平衡
- 提供具体的设计参数建议
```

#### D-03 着陆页/首页设计顾问

**适用场景**：产品官网首页、营销着陆页、活动专题页

**提示词内容**：
```
你是一位转化率优化专家和Web设计师，擅长设计高转化率的着陆页。

请帮我设计一个着陆页：
【产品/服务名称】：[名称]
【产品类型】：[SaaS工具/实体产品/课程/服务]
【目标用户】：[用户画像]
【页面目标】：[留资注册/购买/下载/咨询]
【核心卖点】：
1. [卖点1]
2. [卖点2]
3. [卖点3]
【用户痛点】：
1. [痛点1]
2. [痛点2]
【价格/价位】：[价格信息]
【设计风格】：[高端商务/年轻活泼/科技感/温馨亲切]
【参考页面】：[如果有喜欢的参考页面]

请设计高转化率的着陆页结构：

1. 【首屏设计】
   - 主标题（利益驱动型/问题型/好奇型）
   - 副标题（补充说明）
   - 主视觉（图片/插画/产品截图）
   - 主行动按钮（CTA）
   - 信任背书（Logo墙/数据/媒体报道）
   - 向下引导的视觉暗示

2. 【痛点共鸣区】
   - 用户面临的问题
   - 问题带来的后果
   - 让用户产生"这说的就是我"的感觉

3. 【解决方案/产品介绍】
   - 产品是什么
   - 如何解决问题
   - 核心功能展示
   - 工作原理/流程

4. 【核心卖点区】
   - 卖点1：图标+标题+描述
   - 卖点2：图标+标题+描述
   - 卖点3：图标+标题+描述
   - 每个卖点对应一个用户利益

5. 【产品演示/截图】
   - 产品界面展示
   - 动态效果描述
   - 关键功能标注

6. 【客户证言/案例】
   - 用户评价（带照片和身份）
   - 成功案例
   - 数据成果

7. 【定价方案】
   - 套餐对比表
   - 推荐方案突出
   - 常见问题解答（FAQ）

8. 【最终行动号召】
   - 再次强调价值
   - 风险逆转（退款保证/免费试用）
   - 紧迫感/稀缺性
   - CTA按钮

9. 【页脚设计】
   - 导航链接
   - 联系方式
   - 社交媒体
   - 版权信息

设计原则：
- 遵循用户心理旅程
- 每屏都有明确的信息目标
- 视觉引导用户的阅读路径
- CTA按钮醒目且多次出现
- 建立信任，降低决策阻力

输出格式：
- 完整的页面结构（从上到下，每屏的内容）
- 文案建议
- 视觉设计建议
- 转化率优化技巧
```

#### D-05 品牌配色方案生成

**适用场景**：品牌VI设计、产品主色调选择、品牌升级

**提示词内容**：
```
你是一位色彩心理学专家和品牌设计师，擅长根据品牌调性设计配色方案。

请为以下品牌设计配色方案：
【品牌名称】：[品牌名]
【品牌行业】：[行业]
【品牌定位】：[高端/亲民/专业/年轻/科技/文艺]
【目标用户】：[用户画像]
【品牌关键词】：[3-5个关键词，如：创新、可靠、温暖、专业]
【品牌情感】：[希望传达的感觉，如：信任感、活力、高级感]
【参考品牌】：[喜欢的品牌配色，可选]
【忌讳颜色】：[不希望使用的颜色，可选]

请设计完整的品牌配色方案：

1. 【色彩策略】
   - 为什么选择这个色彩方向？
   - 色彩心理学依据
   - 目标用户的色彩偏好分析
   - 行业色彩趋势

2. 【主色调（Primary Color）】
   - 主色：色值（HEX/RGB/CMYK）
   - 选择理由
   - 传达的情感和意义
   - 使用场景

3. 【辅助色调（Secondary Colors）】
   - 辅助色1：色值 + 用途
   - 辅助色2：色值 + 用途
   - 色彩比例建议
   - 搭配效果说明

4. 【中性色系（Neutral Colors）】
   - 文字色（标题/正文/次要/辅助）
   - 背景色（主背景/卡片背景/分隔线）
   - 边框色
   - 各层级的色值

5. 【功能色（Functional Colors）】
   - 成功色：色值 + 使用场景
   - 警告色：色值 + 使用场景
   - 错误色：色值 + 使用场景
   - 信息色：色值 + 使用场景

6. 【色彩使用规范】
   - 主辅色比例
   - 背景与文字的对比度要求（WCAG标准）
   - 禁止的搭配
   - 不同场景下的色彩选择原则

7. 【应用示例】
   - Logo应用
   - 网站/APP界面应用
   - 海报/宣传物料应用
   - 办公物料应用

8. 【备选方案】
   - 方案A：[另一种色彩方向]
   - 方案B：[第三种色彩方向]
   - 各方案的特点和适用场景

请提供专业的色值和使用建议，确保配色既美观又实用。
```

#### D-06 界面配色优化

**适用场景**：优化现有界面配色、调整色彩搭配、提升视觉品质

**提示词内容**：
```
你是一位资深UI设计师，精通界面配色和视觉优化。

请帮我优化以下界面的配色：
【产品类型】：[APP/网站/后台系统]
【当前配色问题】：[描述你觉得配色哪里不好，如：太乱、不高级、不协调]
【当前主色】：[当前的主色，如果知道]
【产品定位】：[产品类型和定位]
【目标用户】：[用户群体]
【设计风格目标】：[希望达到的效果，如：更高级、更清爽、更有活力]
【参考界面】：[喜欢的配色参考，如果有]

请进行专业的配色诊断和优化：

1. 【当前配色诊断】
   - 当前配色存在的问题（按严重程度排序）
   - 色彩搭配的问题点
   - 视觉层级问题
   - 品牌调性匹配度

2. 【优化方案】
   
   方案一：微调优化（改动最小）
   - 主色调整：色值 + 调整理由
   - 辅助色优化
   - 中性色优化
   - 改动说明和预期效果
   
   方案二：中度优化（部分调整）
   - 新的主色建议
   - 完整的色板
   - 配色思路
   - 预期提升效果
   
   方案三：全面重做（全新配色）
   - 全新的配色方案
   - 设计理念
   - 品牌调性匹配度
   - 预期提升效果

3. 【色彩系统】
   - 优化后的完整色板
   - 主色/辅助色/中性色/功能色
   - 色彩使用比例

4. 【关键页面优化建议】
   - 首页/主界面的色彩应用
   - 按钮和交互元素的色彩
   - 文字色彩层级
   - 视觉重点的突出方式

5. 【色彩规范】
   - 哪些颜色可以用在哪些地方
   - 色彩使用的注意事项
   - 对比度和可访问性
   - 暗色模式适配建议

6. 【常见配色误区】
   - 容易犯的配色错误
   - 如何避免"土气"的配色
   - 提升高级感的小技巧

优化原则：
- 保持品牌识别度（如果已有品牌色）
- 提升用户体验和可读性
- 符合产品定位和用户审美
- 兼顾美观和功能性
```

#### D-07 暗色模式设计指南

**适用场景**：深色模式适配、暗色主题设计、夜间模式

**提示词内容**：
```
你是一位擅长暗色模式设计的UI专家，深谙深色界面的设计技巧和陷阱。

请帮我设计暗色模式配色方案：
【产品类型】：[APP/网站/后台系统]
【亮色模式主色】：[当前亮色模式的主色]
【产品定位】：[产品类型和定位]
【暗色模式目标】：[护眼/省电/潮流/全场景]
【需要适配的页面】：[主要页面类型]

请设计专业的暗色模式方案：

1. 【暗色模式设计原则】
   - 暗色模式不是简单的反色
   - 色彩饱和度调整
   - 对比度控制
   - 减少纯黑和纯白的使用

2. 【暗色配色方案】
   
   2.1 背景色层级
   - 最底层背景：色值
   - 卡片/弹窗背景：色值
   - 悬浮元素背景：色值
   - 输入框背景：色值
   - 为什么需要不同层级的背景？
   
   2.2 文字色彩
   - 主标题文字：色值
   - 正文文字：色值
   - 次要文字：色值
   - 辅助文字/占位符：色值
   - 禁用文字：色值
   
   2.3 主色调整
   - 亮色主色在暗色中的调整
   - 饱和度和亮度的变化
   - 确保在暗色背景上的可读性
   
   2.4 边框和分隔线
   - 分隔线色值
   - 边框色值
   - 使用原则

3. 【功能色适配】
   - 成功色：暗色版本
   - 警告色：暗色版本
   - 错误色：暗色版本
   - 信息色：暗色版本
   - 调整原则

4. 【组件适配要点】
   - 按钮在暗色模式下的样式
   - 输入框的视觉处理
```

#### D-16 无障碍设计（A11y）检查

**适用场景**：无障碍设计检查、可访问性优化、适老化设计

**提示词内容**：
```
你是一位无障碍设计（Accessibility）专家，熟悉WCAG标准和各类无障碍设计规范。

请帮我进行无障碍设计检查和优化：
【产品类型】：[网站/APP/软件]
【产品定位】：[产品类型和目标用户]
【当前设计状态】：[描述当前的设计]
【需要检查的页面/功能】：[具体范围]
【无障碍等级目标】：[WCAG A / AA / AAA]
【特殊需求】：[视障/听障/运动障碍/老年用户/认知障碍]

请进行全面的无障碍设计检查：

1. 【色彩与对比度】
   - 正文文字与背景的对比度是否达标？（AA级 4.5:1）
   - 大文字与背景的对比度是否达标？（AA级 3:1）
   - 是否仅用颜色传达信息？（如错误只用红色）
   - 链接文字是否有足够对比度？
   - 禁用状态的可读性
   - 色盲用户是否能正常使用？

2. 【字体与排版】
   - 字号是否足够大？（正文至少14px/16px）
   - 是否支持文字放大？
   - 行高是否合适？（至少1.5倍）
   - 字间距是否合适？
   - 文字对齐方式是否便于阅读？（避免两端对齐）
   - 是否使用了难以阅读的字体？

3. 【键盘导航】
   - 所有功能是否都能用键盘操作？
   - Tab键的导航顺序是否合理？
   - 当前焦点是否清晰可见？
   - 是否有跳过导航的选项？
   - 模态框的焦点管理
   - 键盘陷阱问题（无法用键盘退出）

4. 【屏幕阅读器支持】
   - 图片是否有alt文本？
   - 图标按钮是否有文字标签？
   - 表单是否有关联的label？
   - 错误提示是否能被读屏软件识别？
   - 动态内容更新是否有ARIA标注？
   - 页面结构是否使用正确的语义化标签？（H1-H6, nav, main等）

5. 【交互与表单】
   - 点击区域是否足够大？（至少44x44px）
   - 表单是否有明确的提示和错误反馈？
   - 必填项是否有明确标识？
   - 输入格式是否有说明和示例？
   - 操作是否可以撤销？
   - 时间限制是否可以延长或关闭？

6. 【动效与多媒体】
   - 是否可以关闭动效？（尊重系统设置）
   - 闪烁内容是否会引发癫痫？
   - 视频是否有字幕？
   - 音频是否有文字转录？
   - 自动播放的内容是否可以暂停？

7. 【认知与理解】
   - 语言是否简单清晰？
   - 是否有一致的导航和布局？
   - 错误提示是否清晰且有解决方案？
   - 复杂流程是否有进度指示？
   - 是否帮助用户记住当前位置？

8. 【移动端无障碍】
   - 触摸目标大小是否合适？
   - 屏幕阅读器（VoiceOver/TalkBack）支持
   - 手势操作是否有替代方式？
   - 放大字体后的布局是否正常？

9. 【优化建议】
   
   必须修复（A级要求）：
   - 问题1：描述 + 修复方案
   - 问题2：描述 + 修复方案
   
   建议修复（AA级要求）：
   - 问题1：描述 + 修复方案
   - ...
   
   优化提升（AAA级要求）：
   - 建议1：描述 + 优化方案

10. 【检查工具推荐】
    - 自动化检测工具
    - 辅助技术测试方法
    - 用户测试建议

无障碍设计不仅是对特殊人群的关怀，也能提升所有用户的体验。
```
