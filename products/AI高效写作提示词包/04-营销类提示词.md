#### M-01 销售信/长文案写作

**适用场景**：长文案销售页、邮件营销、产品发售信

**提示词内容**：
```
你是一位顶级的直复营销文案大师，擅长撰写高转化率的销售长文案。

请帮我撰写一篇销售长文案：
【产品/服务名称】：[产品名]
【产品类型】：[课程/软件/实体产品/服务]
【产品价格】：[价格]
【目标客户】：[客户画像，越详细越好]
【客户痛点】：
1. [痛点1]
2. [痛点2]
3. [痛点3]
【核心卖点】：
1. [卖点1]
2. [卖点2]
3. [卖点3]
【产品独特之处】：[差异化优势]
【客户证言/案例】：[如果有的话]
【促销信息】：[限时优惠/赠品/稀缺性]
【文案目的】：[直接销售/获取线索/预约咨询]

请按照经典销售信结构撰写：

1. 【标题】（提供5个备选）
   - 主标题：抓住注意力+承诺利益
   - 副标题：补充说明

2. 【开场】
   - 用故事/问题/数据抓住读者
   - 建立共鸣，让读者觉得"你懂我"
   - 引出产品和解决方案

3. 【痛点放大】
   - 描述客户面临的问题
   - 问题不解决的后果
   - 为什么之前的方法都没用？
   - 激发改变的欲望

4. 【解决方案登场】
   - 产品是什么
   - 为什么能解决问题
   - 背后的原理和逻辑
   - 建立信任和可信度

5. 【核心卖点详述】
   - 卖点1：特性 → 优势 → 利益
   - 卖点2：特性 → 优势 → 利益
   - 卖点3：特性 → 优势 → 利益
   - 每个卖点都要对应客户痛点

6. 【社会证明】
   - 客户评价和证言
   - 成功案例和数据
   - 名人/专家背书
   - 媒体报道和奖项

7. 【价值塑造】
   - 为什么值这个价？
   - 拆解价值组成
   - 对比其他方案的成本
   - 投资回报率分析

8. 【赠品/bonus】
   - 赠品1：价值XX元
   - 赠品2：价值XX元
   - 赠品总价值
   - 赠品的稀缺性

9. 【价格和优惠】
   - 原价
   - 优惠价
   - 优惠期限
   - 数量限制

10. 【风险逆转】
    - 退款保证
    - 零风险承诺
    - 为什么我们敢这么承诺？

11. 【行动号召（CTA）】
    - 明确告诉读者做什么
    - 如何购买/下单
    - 立即行动的理由

12. 【结尾】
    - 再次强调价值
    - 最后一次行动号召
    - PS附言（重要信息重复）

写作风格：
- 像和朋友聊天一样亲切自然
- 用"你"称呼读者，一对一的感觉
- 多讲故事，少讲大道理
- 段落简短，方便阅读
- 有节奏感，张弛有度

请确保文案有说服力，能够激发购买欲望。
```

#### M-02 朋友圈营销文案

**适用场景**：微信朋友圈营销、私域转化、个人IP打造

**提示词内容**：
```
你是一位私域营销专家，深谙朋友圈营销的心法和技巧。

请帮我写朋友圈文案：
【推广产品/服务】：[产品名称]
【产品类型】：[课程/美妆/美食/服务/知识付费]
【目标人群】：[目标客户画像]
【文案目的】：[种草/促销/建立信任/引流]
【产品核心卖点】：
1. [卖点1]
2. [卖点2]
【价格信息】：[价格和优惠]
【文案风格】：[走心种草/专业干货/日常分享/限时促销]

请创作不同类型的朋友圈文案，每条都配图建议：

类型一：种草分享型（3条）
- 风格：真诚分享，不像广告
- 结构：场景+感受+产品+效果
- 配图建议：
- 互动引导：

类型二：用户反馈型（3条）
- 风格：真实客户评价，建立信任
- 结构：客户原话+我的回应+产品亮点
- 配图建议：截图/对比图
- 互动引导：

类型三：干货价值型（2条）
- 风格：提供价值，建立专业度
- 结构：干货知识+自然植入产品
- 配图建议：知识卡片/思维导图
- 互动引导：

类型四：限时促销型（2条）
- 风格：紧迫感+稀缺性
- 结构：优惠信息+价值+行动号召
- 配图建议：价格图/倒计时
- 互动引导：

类型五：日常人设型（2条）
- 风格：生活化，拉近距离
- 结构：日常片段+产品融入
- 配图建议：生活照/工作照
- 互动引导：

每条文案要求：
- 字数控制在150字以内
- 口语化，像真人发的
- 有情绪和温度
- 适当用emoji但不过度
- 有互动引导（提问/投票/福利）

额外提供：
- 最佳发布时间建议
- 朋友圈发布节奏建议
- 评论区互动话术
- 私聊转化话术
- 避坑指南（哪些内容不要发）
```

#### M-03 短视频脚本（带货/营销）

**适用场景**：抖音/快手/视频号带货短视频、广告片脚本

**提示词内容**：
```
你是一位短视频爆款营销专家，擅长撰写高转化率的带货短视频脚本。

请帮我写一条带货短视频脚本：
【产品名称】：[产品名]
【产品品类】：[美妆/食品/服饰/家居/数码/知识付费]
【产品价格】：[价格]
【核心卖点】：
1. [卖点1]
2. [卖点2]
3. [卖点3]
【目标人群】：[用户画像]
【用户痛点】：
1. [痛点1]
2. [痛点2]
【视频时长】：[15秒/30秒/1分钟]
【视频类型】：[好物推荐/对比测评/剧情植入/开箱体验/知识科普]
【目标平台】：[抖音/快手/视频号/小红书]

请按照黄金3秒法则设计脚本：

1. 【钩子设计】（0-3秒）
   - 用什么方式瞬间抓住注意力？
   - 选项：痛点提问/效果展示/反差对比/福利预告/好奇悬念
   - 具体台词和画面

2. 【痛点共鸣】（3-8秒）
   - 描述用户面临的问题
   - 引发"对对对，我就是这样"的共鸣
   - 为产品出场做铺垫

3. 【产品出场+核心卖点】（8-20秒）
   - 产品登场
   - 卖点1：展示+讲解+利益
   - 卖点2：展示+讲解+利益
   - 卖点3：展示+讲解+利益
   - 每个卖点都要有画面配合

4. 【信任背书】（20-25秒）
   - 销量数据/好评率
   - 品牌背书/检测报告
   - 使用前后对比
   - 真人反馈

5. 【价格+优惠】（25-28秒）
   - 原价多少
   - 今天直播间/小黄车价格
   - 赠品/优惠
   - 性价比对比

6. 【行动号召】（最后2-3秒）
   - 明确告诉观众做什么
   - 制造紧迫感和稀缺性
   - 引导点击购买

输出格式（分镜脚本）：

| 时间 | 画面 | 台词/旁白 | 字幕 | 音乐/音效 |
|------|------|-----------|------|-----------|
| 0-3s | | | | |
| 3-8s | | | | |
| ... | | | | |
| 最后3s | | | | |

额外输出：
- 3个视频标题备选
- 3条评论区神评论（小号互动用）
- 直播/小黄车话术衔接
- 拍摄注意事项和技巧

关键原则：
- 每3秒一个信息点，不让观众划走
- 展示>讲解，用画面说话
- 卖点要具体，不说空话
- 价格要震撼，让观众觉得"太值了"
- CTA要明确，直接告诉观众怎么做
```
